# Angular UDataView

ID: angular.data-view

Framework: angular; availability: public

## Authored interpretation

Collection presenter that renders each item as text in a list or grid with optional paging, filtering, sorting, lazy loading and loading/empty states.

## Framework surface

Selector u-data-view; standalone generic UDataView<T=unknown>, OnPush, ViewEncapsulation.None, componentName "dataview". Inputs value: T[]=[], itemTemplate: required (item:T,layout:"list"|"grid")=>string, layout: "list"|"grid"="list", paginator=false, first=0, rows=0, totalRecords?: number, pageLinkSize=5, rowsPerPageOptions: number[]=[], paginatorPosition: "top"|"bottom"|"both"="bottom", alwaysShowPaginator=true, currentPageReportTemplate="{first} to {last} of {totalRecords}", sortField="", sortOrder: 1|-1=1, lazy=false, loading=false, loadingIcon="u-loading-icon", emptyMessage="No results found", dataKey="", trackBy=(index,item)=>item, filterBy="" (comma-separated field paths), filterLocale?: string. Outputs pageChange: PaginatorPageChangeEvent and onLazyLoad: {first:number;rows:number;sortField:string;sortOrder:1|-1}. Public filter(query:unknown, mode: MatchMode="contains"):void stores the query, resets the page offset to 0 and, when lazy, emits onLazyLoad. ngOnChanges seeds the internal first/rows signals when those inputs change and emits onLazyLoad when lazy and first/rows/sortField/sortOrder/lazy change. The MatchMode union (contains/startsWith/endsWith/equals/notEquals/in/lt/lte/gt/gte), field(), matches() and compare() are non-exported module-level helpers; matching is case-insensitive via toLocaleLowerCase, with numeric comparison for lt/lte/gt/gte. Non-lazy pipeline is filter, then sort (nullish values first, numbers numerically, otherwise localeCompare, multiplied by sortOrder), then slice by first/rows when paginator is on and rows>0; recordCount is totalRecords (falling back to value length) when lazy. Items are rendered as interpolated text from itemTemplate, not as projected templates. Grid layout renders div role=list/listitem; list layout renders ul/li; an empty collection renders emptyMessage. The paginator composes UPaginator top, bottom or both and a rows-per-page select plus an aria-live page report with {first},{last},{totalRecords},{currentPage},{totalPages},{rows} placeholders; changeRows(rows) ignores rows<=0. While loading, the root sets aria-busy and a role=status span shows USpinnerIcon with visually hidden text "Loading" (a GAP-124 comment records the spinner as a scope exception). Identity for track-by is dataKey field or trackBy. dataViewStyleModule is a local source-only {css, classes} module (generated by g3e-port per its comment) whose classes root/list/listItem resolve u-data-view, u-data-view-grid|u-data-view-list and u-data-view-item; it does not wrap @ultimate/uix-styles. Consumer availability: @ultimate/ng#UDataView only; the root barrel re-exports ./data-view and no ./data-view manifest subpath exists. All components extend UBaseComponent with inherited dt?: Record<string,unknown> and unstyled?: boolean; base ngOnInit registers theme variables and structural CSS. Local style modules and their css/classes are source-only, owned by this family. Remaining private/protected state, lifecycle methods, render handlers and module-level helpers belong to the owning record. No additional directive, hook, factory or base class is declared in these roots. Aura registers this component's preset through the themes package; that relationship does not prove runtime completeness. No component-metadata record exists for this family in this revision. Manifest dist targets declare availability, not verified publication or installed artifact integrity. Prime comments are neutral provenance references only.
