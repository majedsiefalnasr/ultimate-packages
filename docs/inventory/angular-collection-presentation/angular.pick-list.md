# Angular UPickList

ID: angular.pick-list

Framework: angular; availability: public

## Authored interpretation

Dual-list transfer control that moves items between a source and a target list, with per-side filtering, reordering, disabled options and optional drag-and-drop.

## Framework surface

Selector u-pick-list; standalone UPickList (non-generic), OnPush, ViewEncapsulation.None, componentName "picklist". Inputs source/target: unknown[]=[], dataKey="", dragdrop=false, disabled=false, metaKeySelection=false, filterBy="", filterMatchMode: MatchMode="contains", filterLocale?: string, showSourceFilter/showTargetFilter/showSourceControls/showTargetControls=true, sourceHeader="Source", targetHeader="Target", sourceOptionDisabled/targetOptionDisabled?: string|((item:unknown)=>boolean), sourceStyle/targetStyle: Record<string,string|number>={} applied with NgStyle, sourceTrackBy/targetTrackBy=(index,item)=>identity(item)??item, breakpoint="960px". Outputs sourceChange and targetChange: unknown[]; inputs are not mutated and each change emits fresh arrays. Four transfer buttons (To Target, All To Target, To Source, All To Source) call transfer(side, all), which moves only enabled items (selected ones unless all), emits both sides and clears the selection; per-side Move up/top/down/bottom controls reorder only enabled items so disabled ones keep their positions. An option is disabled by a string field path (truthy value) or a predicate. Identity/label come from dataKey or the item itself. Optional per-side filter inputs are gated by filterBy and showSourceFilter/showTargetFilter and use the non-exported MatchMode/field/matches helpers. With dragdrop false each side renders UListbox from @ultimate/ng/listbox (multiple, ngModel standalone) and fromListbox writes the normalized selection back via writeValue on the ViewChildren listbox; with dragdrop true each side is a CDK cdkDropList inside cdkDropListGroup and drop() uses moveItemInArray within a side or transferArrayItem across sides, skipping disabled items. metaKeySelection collapses plain-click selection to one item unless ctrl/meta is held. A Renderer2 effect writes a responsive @media (max-width: breakpoint) rule into an appended style element, keyed by the module-level nextPickListId root id. pickListStyleModule is a local source-only {css, classes} module (generated by g3e-port) with root/sourceList/targetList/controls/list/listItem/itemSelected resolvers; it does not wrap @ultimate/uix-styles. Consumer availability: @ultimate/ng#UPickList only; the root barrel re-exports ./pick-list and no ./pick-list manifest subpath exists. All components extend UBaseComponent with inherited dt?: Record<string,unknown> and unstyled?: boolean; base ngOnInit registers theme variables and structural CSS. Local style modules and their css/classes are source-only, owned by this family. Remaining private/protected state, lifecycle methods, render handlers and module-level helpers belong to the owning record. No additional directive, hook, factory or base class is declared in these roots. Aura registers this component's preset through the themes package; that relationship does not prove runtime completeness. No component-metadata record exists for this family in this revision. Manifest dist targets declare availability, not verified publication or installed artifact integrity. Prime comments are neutral provenance references only.
