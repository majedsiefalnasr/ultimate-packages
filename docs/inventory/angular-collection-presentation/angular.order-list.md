# Angular UOrderList

ID: angular.order-list

Framework: angular; availability: public

## Authored interpretation

Reorderable single-column list with move up/top/down/bottom controls, filtering, multi-selection and optional drag-and-drop.

## Framework surface

Selector u-order-list; standalone UOrderList (non-generic), OnPush, ViewEncapsulation.None, componentName "orderlist", implements AfterViewChecked. Exported interface UOrderListButtonProps has optional class/id/title/name/value:string, tabindex:number and disabled:boolean. Inputs value: unknown[]=[], dataKey="", filterBy="", filterMatchMode: MatchMode="contains", filterLocale?: string, dragdrop=false, metaKeySelection=false, breakpoint="960px", scrollHeight="14rem", stripedRows=false, disabled=false, tabindex=0, ariaLabel="Order list", buttonProps, moveUpButtonProps, moveTopButtonProps, moveDownButtonProps, moveBottomButtonProps: UOrderListButtonProps={}. Output valueChange: unknown[]; the component never mutates its input value and always emits a new array. Four controls render "Move up/top/down/bottom" buttons disabled when disabled, nothing is selected or the per-direction props disable them; button props merge shared buttonProps with the direction-specific props and concatenate class values. up/down moves shift each selected item past an unselected neighbour (iterating in reverse for down); top/bottom gather the selection before or after the remainder. Identity and label come from dataKey field or the item itself. Optional filter renders a role=searchbox input and matches filterBy comma-separated paths with the non-exported MatchMode/field/matches helpers (case-insensitive, numeric lt/lte/gt/gte). With dragdrop false the list renders UListbox from @ultimate/ng/listbox (multiple, ngModel-bound via FormsModule) and ngAfterViewChecked sets the inner listbox tabindex through Renderer2; with dragdrop true it renders a CDK cdkDropList ul with role=listbox/option, click and Enter/Space selection, and drop() maps visible indices back to the full value before moveItemInArray and emitting valueChange. metaKeySelection collapses plain-click selection to a single item unless ctrl/meta is held. An effect writes a responsive @media (max-width: breakpoint) rule into a style element created via Renderer2 and appended to the host; a module-level nextOrderListId assigns the root id used by that rule. orderListStyleModule is a local source-only {css, classes} module (generated by g3e-port) with root/controls/list/listItem/itemSelected class resolvers; it does not wrap @ultimate/uix-styles. Consumer availability: @ultimate/ng#UOrderList and @ultimate/ng#UOrderListButtonProps; the root barrel re-exports ./order-list and no ./order-list manifest subpath exists. All components extend UBaseComponent with inherited dt?: Record<string,unknown> and unstyled?: boolean; base ngOnInit registers theme variables and structural CSS. Local style modules and their css/classes are source-only, owned by this family. Remaining private/protected state, lifecycle methods, render handlers and module-level helpers belong to the owning record. No additional directive, hook, factory or base class is declared in these roots. Aura registers this component's preset through the themes package; that relationship does not prove runtime completeness. No component-metadata record exists for this family in this revision. Manifest dist targets declare availability, not verified publication or installed artifact integrity. Prime comments are neutral provenance references only.
