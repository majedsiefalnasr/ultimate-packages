# MultiSelect

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

MultiSelect is a dropdown that selects several options from a list. A closed trigger shows the selection as a comma-separated label or as chips; opening it shows an overlay with an optional header (toggle-all checkbox and filter input) and a list where each option has a checkbox. It supports option groups, templates, a selection limit, a loading state and virtual scrolling (`primeng-21.1.9:packages/primeng/src/multiselect/multiselect.ts`, `primevue-4.5.5:packages/primevue/src/multiselect/MultiSelect.vue`, `primereact-10.9.9:components/lib/multiselect/MultiSelect.js`).

## 2. Names & status

- Canonical name: **MultiSelect** in all three frameworks; no legacy aliases.
- PrimeNG selectors: `p-multiSelect`, `p-multiselect`, `p-multi-select`; `styleClass` deprecated since v20.0.0 (use `class`); the `removetokenicon` template is `@deprecated Use chipicon instead` (`primeng-21.1.9:packages/primeng/src/multiselect/multiselect.ts`, `primeng-21.1.9:packages/primeng/src/types/multiselect/multiselect.types.ts`).
- PrimeVue: `panelStyle` / `panelClass` deprecated since v4.0 (use `overlayStyle` / `overlayClass`); `removetokenicon` slot deprecated since v4.0 (use `chipicon`) (`primevue-4.5.5:packages/primevue/src/multiselect/MultiSelect.d.ts`).
- PrimeReact: no deprecations in `multiselect.d.ts`.
- Listed in the Form group of all three showcase menus (`primeng-21.1.9:apps/showcase/assets/data/menu.json`, `primevue-4.5.5:apps/showcase/assets/menu/menu.json`, `primereact-10.9.9:components/layout/menu.json`).

## 7. Accessibility

- A visually hidden `input` with `role="combobox"`, `aria-haspopup="listbox"`, `aria-expanded` and `aria-controls` receives focus; the overlay list is `role="listbox"` with `aria-multiselectable="true"`, options are `role="option"` with `aria-selected`; the filter input is `role="searchbox"` (`primeng-21.1.9:packages/primeng/src/multiselect/multiselect.ts`, `primevue-4.5.5:packages/primevue/src/multiselect/MultiSelect.vue`, `primereact-10.9.9:components/lib/multiselect/MultiSelect.js`, `primereact-10.9.9:components/lib/multiselect/MultiSelectPanel.js`).
- Keyboard on the trigger: Tab, Space/Enter/Down to open, Up, printable characters (type-ahead). In the overlay: Tab / Shift+Tab across header elements, Enter/Space toggle, Escape closes, Up/Down/Home/End navigate; PrimeVue and PrimeNG additionally document Alt+Up, Shift+arrow/Space range selection, Ctrl+Shift+Home/End, Ctrl+A and Page Up/Down. PrimeReact's doc has the shorter list (`primeng-21.1.9:apps/showcase/doc/multiselect/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/multiselect/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/multiselect/accessibilitydoc.js`).
- PrimeReact gaps: the combobox input does not set `aria-haspopup`; the header has a close button labelled with the locale `close` key (`primereact-10.9.9:components/lib/multiselect/MultiSelect.js`, `primereact-10.9.9:components/lib/multiselect/MultiSelectHeader.js`).
- Locale keys `selectAll` / `unselectAll` label the toggle-all checkbox in all three docs.

## 9. Relationships

- Embeds: Checkbox (option and toggle-all), Chip (NG/Vue chip display), InputText + IconField/InputIcon (filter), VirtualScroller / Scroller, Overlay (NG) / Portal (Vue, React), Tooltip (NG, React), Ripple.
- Shares the option/filter/keyboard model with Listbox (inline) and Select (single value).
- Related: AutoComplete with `multiple`, TreeSelect (hierarchical multi-selection).
