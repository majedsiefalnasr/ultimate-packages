# FileUpload

**Category:** File · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

FileUpload is a file picker plus uploader. It has two modes: `advanced` (a header with Choose / Upload / Cancel buttons and a content area that lists pending and completed files, shows a progress bar and validation messages, and accepts drag and drop) and `basic` (a single choose button with a file label). It validates files (type, size, count), previews image files, and either posts a `FormData` itself or hands the files to application code (`customUpload`). All three frameworks ship it (`primeng-21.1.9:packages/primeng/src/fileupload/fileupload.ts`, `primevue-4.5.5:packages/primevue/src/fileupload/FileUpload.vue`, `primereact-10.9.9:components/lib/fileupload/FileUpload.js`).

## 2. Names & status

- Canonical name: **FileUpload**. Not a legacy alias of anything and not deprecated in any framework (no `@deprecated` tag inside the PrimeNG component; the catalog marks no FileUpload prop as deprecated).
- **Menu naming:** the showcase menus file the component under a category called **File**, whose only entry is labelled **Upload** (route `/fileupload`). The label "Upload" is a menu label only; the component, selector, import path, route and CSS prefix all use `FileUpload` / `fileupload`. This holds identically in PrimeNG (`routerLink`), PrimeVue and PrimeReact (`to`) (`primeng-21.1.9:apps/showcase/assets/data/menu.json`, `primevue-4.5.5:apps/showcase/assets/menu/menu.json`, `primereact-10.9.9:components/layout/menu.json`).
- Page titles differ slightly: PrimeNG header "FileUpload" with doc title "Angular FileUpload Component" (`primeng-21.1.9:apps/showcase/pages/fileupload/index.ts`); PrimeVue header "File Upload" with title "Vue File Upload Component" (`primevue-4.5.5:apps/showcase/pages/fileupload/index.vue`).
- PrimeNG accepts two selector spellings, `p-fileupload` and `p-fileUpload` (`primeng-21.1.9:packages/primeng/src/fileupload/fileupload.ts`).
- Internal helper `FileContent` (renders a file row list) exists in PrimeNG (`[pFileContent]`) and PrimeVue (`FileContent.vue`, `hostName: 'FileUpload'`); PrimeReact inlines the same markup in `createFile`. It is not part of the documented API.

## 6. Usage guidance

- **Import** — one import line per framework (`primeng-21.1.9:apps/showcase/doc/fileupload/import-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/ImportDoc.vue`, `primereact-10.9.9:components/doc/fileupload/importdoc.js`).
- **Basic** — `mode="basic"` gives a compact single-button uploader as the alternative to the default advanced mode; the demos pair `name`, `url`, `accept="image/*"` and `maxFileSize` and use an external trigger or the built-in click to upload (`primeng-21.1.9:apps/showcase/doc/fileupload/basic-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/BasicDoc.vue`, `primereact-10.9.9:components/doc/fileupload/basicdoc.js`). The PrimeNG demo calls `upload()` on the component reference from a separate Button.
- **Auto** — with `auto` set, the upload starts immediately after selection, so no Upload step or file label is shown (`primeng-21.1.9:apps/showcase/doc/fileupload/auto-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/AutoDoc.vue`, `primereact-10.9.9:components/doc/fileupload/autodoc.js`).
- **Advanced** — the default mode adds drag and drop, multiple files, progress tracking and validation; the demos set `multiple` and supply an empty-state template (`primeng-21.1.9:apps/showcase/doc/fileupload/advanced-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/AdvancedDoc.vue`, `primereact-10.9.9:components/doc/fileupload/advanceddoc.js`).
- **Template** — replace the header, the content area, the per-file row and the empty state; the demos build a custom toolbar with a total-size ProgressBar, Pending / Completed groups with Badge and remove Buttons, and use the callbacks passed into the templates (`primeng-21.1.9:apps/showcase/doc/fileupload/template-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/TemplateDoc.vue`, `primereact-10.9.9:components/doc/fileupload/templatedoc.js`). The PrimeNG demo also needs `MessageService` and Toast for feedback and reads `fileSizeTypes` from the PrimeNG config.
- **Custom upload** — set `customUpload` and handle the files yourself (`uploadHandler` / `uploader`); PrimeVue's demo combines it with `auto` and a `select` handler to preview an image client-side, PrimeReact's converts to base64, PrimeNG's reads the file's `objectURL` into a Blob (`primeng-21.1.9:apps/showcase/doc/fileupload/custom-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/CustomUploadDoc.vue`, `primereact-10.9.9:components/doc/fileupload/customuploaddoc.js`). The PrimeNG file exists but is not registered in its page section list, so the PrimeNG site does not show a Custom Upload section (`primeng-21.1.9:apps/showcase/pages/fileupload/index.ts`).
- **Accessibility** — see Section 7 (`primeng-21.1.9:apps/showcase/doc/fileupload/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/fileupload/accessibilitydoc.js`).
- Services / providers: PrimeNG needs `HttpClient` for built-in uploads (not for `customUpload`); the demos additionally use `MessageService` + Toast for notifications (not required by the component). PrimeVue and PrimeReact need no providers; the demos use Toast.
- The demos post to a Prime-hosted or local `/api/upload` endpoint; any real use must supply a server endpoint that reads multipart form data under the `name` field.

## 7. Accessibility

- All three accessibility docs say the same thing: a hidden native `input type="file"` serves screen readers, and the interactive elements are buttons, so keyboard support is the Button's (`primeng-21.1.9:apps/showcase/doc/fileupload/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/fileupload/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/fileupload/accessibilitydoc.js`). See Button.
- PrimeNG: the hidden input gets an `aria-label` from the locale key `aria.browseFiles`; the choose button also opens on Enter in advanced mode, and in basic mode Space and Enter open the file dialog (`onBasicKeydown`). Decorative icons carry `aria-hidden` (`primeng-21.1.9:packages/primeng/src/fileupload/fileupload.ts`, `primeng-21.1.9:packages/primeng/src/api/translation.ts`).
- PrimeVue: the choose button opens on Enter (`@keydown.enter`) and icons are `aria-hidden="true"`; basic mode triggers the dialog on `mouseup` with the primary mouse button. The hidden input has no explicit `aria-label` (`primevue-4.5.5:packages/primevue/src/fileupload/FileUpload.vue`).
- PrimeReact: the choose control is a `span` button with `tabIndex: 0`, opened by Enter or NumpadEnter; the Upload and Cancel buttons carry `aria-hidden="true"` (the buttons remain focusable), which hides them from assistive technology; icons are `aria-hidden` (`primereact-10.9.9:components/lib/fileupload/FileUpload.js`).
- Validation errors are rendered through Message (PrimeNG, PrimeVue) or Messages (PrimeReact), so they inherit those components' roles. Thumbnails use `role="presentation"` with the file name as `alt`.
- Doc/source mismatch: the docs imply Button-level keyboard support throughout, but PrimeReact's choose control is not a real Button (it is a styled `span`), and its Upload / Cancel Buttons are `aria-hidden`.

## 9. Relationships

- Embeds **Button** (choose, upload, cancel, per-file remove), **ProgressBar** (upload progress), **Badge** (Pending / Completed per file) and **Message** for validation errors (PrimeNG, PrimeVue); PrimeReact uses **Messages** and hand-built choose control, plus Button, ProgressBar, Badge and Ripple.
- Related uploads and inputs: Toast (feedback in every demo), InputText and other form inputs in a form, Image or Galleria for previews of uploaded files, BlockUI (PrimeNG's `BlockableUI` interface is implemented so BlockUI can target it).
- Not embedded by other Prime components. There are no alias chains; the menu label "Upload" is the only alternative name (Section 2).

## 11. Framework differences

| Aspect                      | PrimeNG                                                                  | PrimeVue                                                       | PrimeReact                                                                    |
| --------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Upload transport            | Angular `HttpClient`; `method` (`post`/`put`) and `headers` configurable | `XMLHttpRequest`, POST only; request sent only if `url` is set | `XMLHttpRequest`, POST only                                                   |
| Request hooks               | `onBeforeUpload`, `onSend` (HTTP events)                                 | `before-upload`, `before-send` (`xhr` + `formData`)            | `onBeforeUpload`, `onBeforeSend` (`xhr` + `formData`)                         |
| File-count limit            | `fileLimit` with limit message                                           | `fileLimit` with limit message                                 | not declared; `fileLimit` is read in source but absent from defaults and d.ts |
| Type validation             | `accept` checked, error message shown                                    | `accept` checked, error message shown                          | `accept` only forwarded to the native input; no type check                    |
| Error messages              | structured `{ severity, text }` from summary + detail                    | plain strings in Message                                       | `Messages` entries with summary / detail (advanced mode only)                 |
| Customisation model         | named templates, per-button style classes and `ButtonProps`              | slots, `class`, button props                                   | render-prop templates and `chooseOptions` / `uploadOptions` / `cancelOptions` |
| Per-file template           | `file` template                                                          | none (use `content` slot or `fileremoveicon`)                  | `itemTemplate`                                                                |
| Basic-mode label slot       | `filelabel` template                                                     | `filelabel` slot                                               | `selectedFileLabel` prop                                                      |
| Upload / Cancel with `auto` | hidden                                                                   | shown (header buttons not gated on `auto`)                     | hidden                                                                        |
| Custom upload event         | `uploadHandler` output                                                   | `uploader` emit                                                | `uploadHandler` callback with `{ files, options }`                            |
| Veto hooks                  | n/a                                                                      | n/a                                                            | `onBeforeSelect`, `onBeforeDrop`                                              |
| Imperative API              | component methods                                                        | `upload()` documented                                          | ref handle (`getFiles`, `setFiles`, `getUploadedFiles`, ...)                  |
| Theming                     | `@primeuix` tokens and styles                                            | `@primeuix` tokens and styles                                  | own CSS in `FileUploadBase.js`, no tokens                                     |
| Category in menu            | File > Upload                                                            | File > Upload                                                  | File > Upload                                                                 |

Source/doc mismatches found:

- PrimeVue declares PT key `pcProgressBar` in `FileUpload.d.ts` but the template reads `ptm('pcProgressbar')` (`primevue-4.5.5:packages/primevue/src/fileupload/FileUpload.vue`).
- PrimeVue `onMessageClose` and `clear()` set `messages` to `null`, while later code pushes into `messages`; the type declares `string[] | null` (`primevue-4.5.5:packages/primevue/src/fileupload/FileUpload.vue`).
- PrimeReact `removeUploadedFiles` reads `filesState[index]` (the pending list) to report the removed file, not the uploaded list, so `onRemove` can receive the wrong file (`primereact-10.9.9:components/lib/fileupload/FileUpload.js`).
- PrimeReact assigns to `uploadedFileCount`, a `useRef` constant, inside the `fileLimit` branches, so those branches cannot work as written (`primereact-10.9.9:components/lib/fileupload/FileUpload.js`).
- The PrimeNG `custom-doc.ts` section is not wired into the page, and its intro repeats the basic-mode sentence (`primeng-21.1.9:apps/showcase/doc/fileupload/custom-doc.ts`, `primeng-21.1.9:apps/showcase/pages/fileupload/index.ts`).
- PrimeNG still carries IE11 workaround code (`isIE11`, `clearIEInput`) (`primeng-21.1.9:packages/primeng/src/fileupload/fileupload.ts`).
