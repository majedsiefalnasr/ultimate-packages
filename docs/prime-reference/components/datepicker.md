# DatePicker

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

DatePicker is a text input paired with a calendar overlay. The user either types a date in the input (formatted with a `dateFormat` pattern) or opens a popup panel and picks from a day grid, a month grid or a year grid. The same component also covers multiple dates, date ranges, a time picker (hours, minutes, optional seconds, optional AM/PM; PrimeReact adds milliseconds), several months side by side, and an always-visible `inline` mode with no input at all. Locale texts (day and month names, first day of week, ARIA labels) come from each library's global locale configuration. The panel is anchored to the input, or rendered as a touch-friendly layout (PrimeNG/PrimeReact `touchUI`, PrimeVue `breakpoint`). The component participates in each framework's form binding: Angular `ControlValueAccessor`, Vue `v-model` plus the Forms integration, React controlled `value` / `onChange`.

The canonical name is **DatePicker**. PrimeReact still ships it only under the old name `Calendar`, and PrimeVue keeps a deprecated `Calendar` wrapper; the Ultimate glossary says to avoid "Calendar".

## 2. Names & status

- Canonical name: **DatePicker** (file `datepicker`). Glossary meaning: date and time input with a calendar overlay; "Calendar" is the avoided term.
- PrimeNG: `DatePicker` component, selectors `p-datePicker`, `p-datepicker`, `p-date-picker` (`primeng-21.1.9:packages/primeng/src/datepicker/datepicker.ts`); stable. Deprecated inputs: `styleClass` (since v20.0.0, use `class`), `showTransitionOptions` and `hideTransitionOptions` (since v21.0.0, use `motionOptions`). The old `Calendar` name was renamed in v19 (deprecated alias kept, `primeng-21.1.9:apps/showcase/doc/migration/v19/renamedcomponentsdoc.ts`) and the alias is listed as removed in v20 (`primeng-21.1.9:apps/showcase/doc/migration/v20/removalsdoc.ts`); version 21.1.9 ships no `calendar` folder.
- PrimeVue: `DatePicker`; stable. The legacy `Calendar` component (`primevue-4.5.5:packages/primevue/src/calendar/Calendar.vue`) extends `DatePicker` and logs `Deprecated since v4. Use DatePicker component instead.` on mount; its typings are all `extends DatePicker.*` and carry `@deprecated since v4` (`primevue-4.5.5:packages/primevue/src/calendar/Calendar.d.ts`). Its style module is an empty extension named `calendar` (`primevue-4.5.5:packages/primevue/src/calendar/style/CalendarStyle.js`). The PT options type also keeps a deprecated `calendar` key for it.
- PrimeReact: **`Calendar`** is the only name; there is no `datepicker` folder (`primereact-10.9.9:components/lib/calendar/Calendar.js`). It is the functional equivalent of DatePicker and is not marked deprecated in `primereact-10.9.9:components/lib/calendar/calendar.d.ts`. Treat `Calendar` here as a legacy alias of the canonical name.
- Alias chain: `Calendar` (PrimeNG ≤ v19, PrimeVue 3.x, PrimeReact all versions) → `DatePicker` (PrimeNG ≥ v19, PrimeVue ≥ 4). Only PrimeVue still carries both names in one build.

## 4. Anatomy

PrimeNG/PrimeVue sections (PT keys, `primeng-21.1.9:packages/primeng/src/types/datepicker/datepicker.types.ts`, `primevue-4.5.5:packages/primevue/src/datepicker/DatePicker.d.ts`):

- **root** — wrapper `span`; **pcInputText** — the `InputText` with `role="combobox"`; **clearIcon** (when `showClear`).
- **dropdown** (+ **dropdownIcon**) — the trigger button when `showIcon` and `iconDisplay="button"`; **inputIconContainer** / **inputIcon** — the in-input icon when `iconDisplay="input"`.
- **panel** → optional header slot → **calendarContainer** → one **calendar** per month → **header** with **pcPrevButton**, **title** (**selectMonth**, **selectYear**, **decade**), **pcNextButton**.
- Day view: **dayView** → **table** → **tableHeader** / **tableHeaderRow** (PrimeNG; PrimeVue also **tableHeader**, **tableHeaderRow**) with optional **weekHeader** / **weekHeaderLabel** and **tableHeaderCell** / **weekDayCell** → **weekDay**; **tableBody** → **tableBodyRow** → optional **weekNumber** / **weekLabelContainer** → **dayCell** → **day**.
- Month view: **monthView** → **month**. Year view: **yearView** → **year**.
- **timePicker** → **hourPicker** (**hour**), **separatorContainer** / **separator**, **minutePicker** (**minute**), **secondPicker** (**second**), **ampmPicker** (**ampm**), each with **pcIncrementButton** / **pcDecrementButton**.
- **buttonbar** → **pcTodayButton**, **pcClearButton**; footer template slot after it.
- Hidden live regions: **hiddenSelectedDay**, **hiddenMonth**, **hiddenYear**. PrimeNG also exposes `motion?: MotionOptions`; PrimeVue exposes **transition** and **hooks**.

PrimeReact sections (`CalendarPassThroughOptions`, `primereact-10.9.9:components/lib/calendar/calendar.d.ts`): root, input, dropdownButton, panel, groupContainer, group, header, previousButton, previousIcon, title, monthTitle, yearTitle, decadeTitle, decadeTitleText, nextButton, nextIcon, container, table, tableHeader, tableHeaderRow, weekHeader, tableHeaderCell, weekLabel, weekDay, tableBody, tableBodyRow, weekNumber, weekLabelContainer, day, dayLabel, monthPicker, month, yearPicker, year, timePicker, hourPicker, incrementIcon, incrementButton, decrementButton, decrementIcon, hour, separatorContainer, separator, minutePicker, minute, secondPicker, second, ampmPicker, ampm, buttonbar and further button/footer/hidden-region keys.

## 5. API highlights

- **Model:** PrimeNG `ngModel` / form control holding `Date`, `Date[]` or a 2-element range array; `dataType: 'date' | 'string' = 'date'` selects the emitted type. PrimeVue `modelValue` (`Date | Date[] | (Date | null)[] | null`) with `updateModelType: 'date' | 'string' = 'date'` and `defaultValue`. PrimeReact `value: Nullable<TValue>` + `onChange(event: FormEvent<TValue>)`.
- **Selection:** `selectionMode: 'single' | 'multiple' | 'range'` (default `'single'`); `maxDateCount` caps multiple mode; PrimeVue/PrimeReact `hideOnRangeSelection`; `minDate`, `maxDate`, `disabledDates`, `disabledDays` (all); PrimeReact also `enabledDates`.
- **Views:** `view: 'date' | 'month' | 'year' = 'date'`; `numberOfMonths = 1` (PrimeNG/PrimeVue `responsiveOptions`); `showWeek = false`; `showOtherMonths = true`; `selectOtherMonths = false`; PrimeNG `startWeekFromFirstDayOfYear`, `firstDayOfWeek`; PrimeReact `monthNavigator`, `yearNavigator`, `yearRange`, `viewDate`.
- **Format:** `dateFormat` (default `mm/dd/yy` from locale, tokens `d dd o oo D DD m mm M MM y yy @ !` plus quoted literals); `shortYearCutoff = '+10'`; PrimeReact adds `formatDateTime` / `parseDateTime` callbacks and a `mask` (`maskSlotChar = '_'`).
- **Time:** `showTime = false`, `timeOnly = false`, `hourFormat: '12' | '24'` (default `'24'` in PrimeVue/PrimeReact), `showSeconds = false`, `stepHour` / `stepMinute` / `stepSecond = 1`, `timeSeparator = ':'` (PrimeNG/PrimeVue); PrimeReact `showMillisec`, `stepMillisec`.
- **Overlay:** PrimeNG `appendTo` (falls back to the global `overlayAppendTo`, default `'self'`), `inline`, `showOnFocus = true`, `hideOnDateTimeSelect = true`, `autoZIndex = true`, `baseZIndex = 0`, `focusTrap = true`, `touchUI = false`, `motionOptions`, `panelStyleClass`; PrimeVue `appendTo = 'body'`, `hideOnDateTimeSelect = false`, `breakpoint = '769px'`, `panelClass`; PrimeReact `appendTo = document.body`, `hideOnDateTimeSelect = false`, `touchUI = false`, `visible` + `onVisibleChange`, `transitionOptions`, `panelClassName`.
- **Chrome:** `showIcon = false`, `iconDisplay: 'button' | 'input' = 'button'` (PrimeNG/PrimeVue; PrimeReact `iconPos: 'left' | 'right' = 'right'`), `icon`, `showButtonBar = false`, `showClear = false` (PrimeNG/PrimeVue only), `variant: 'outlined' | 'filled'`, `size: 'small' | 'large'` and `fluid` (PrimeNG/PrimeVue only), `invalid = false`, `disabled = false`, `readonlyInput` (PrimeNG/PrimeReact) / `readonly` (PrimeVue), `manualInput = true` (PrimeVue), `keepInvalid = false` (PrimeNG/PrimeReact).
- **Events:** PrimeNG `onSelect(Date)`, `onShow`, `onClose`, `onBlur`, `onFocus`, `onInput`, `onClear`, `onClearClick`, `onTodayClick(Date)`, `onClickOutside`, `onMonthChange`, `onYearChange`; PrimeVue `date-select`, `show`, `hide`, `blur`, `focus`, `input`, `keydown`, `clear-click`, `today-click`, `month-change`, `year-change`, `value-change`, `update:modelValue`; PrimeReact `onChange`, `onSelect`, `onInput`, `onFocus`, `onBlur`, `onShow`, `onHide`, `onTodayButtonClick`, `onClearButtonClick`, `onMonthChange`, `onViewDateChange`, `onVisibleChange`.
- **Templates:** PrimeNG templates `date`, `disableddate`, `decade`, `header`, `footer`, `buttonbar`, `triggericon`, `inputicon`, `clearicon`, `previousicon`, `nexticon`, `incrementicon`, `decrementicon`; PrimeVue 25 slots (adds per-button slots such as `hourincrementbutton`, `todaybutton`, `weeklabel`, `weekheaderlabel`; icon slot is `previcon`); PrimeReact `dateTemplate`, `decadeTemplate`, `headerTemplate`, `footerTemplate`, `monthNavigatorTemplate`, `yearNavigatorTemplate`.
- **Methods:** PrimeNG `toggle()` (methods doc); PrimeReact `show`, `hide`, `focus`, `getElement`, `getInput`, `getOverlay`, `getViewDate`, `getCurrentDateTime`, `updateViewDate`; PrimeVue has no documented methods.

- Basic: bind a `Date` to the model; PrimeNG via `ngModel` (`primeng-21.1.9:apps/showcase/doc/datepicker/basic-doc.ts`), PrimeVue via `v-model` (`primevue-4.5.5:apps/showcase/doc/datepicker/BasicDoc.vue`), PrimeReact via controlled `value` + `onChange` (`primereact-10.9.9:components/doc/calendar/basicdoc.js`).

## 7. Accessibility

- Input: `role="combobox"`, `aria-autocomplete="none"`, `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls` pointing at the panel id. Labelling by `<label for>` with `inputId`, or `ariaLabelledBy` / `ariaLabel` (PrimeVue prop spelled `ariaLabelledby`); PrimeNG also sets `aria-required` (`primeng-21.1.9:packages/primeng/src/datepicker/datepicker.ts`, `primevue-4.5.5:packages/primevue/src/datepicker/DatePicker.vue`, `primereact-10.9.9:components/lib/calendar/Calendar.js`).
- Trigger button: `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`; label from the locale `aria.chooseDate` key with the formatted value appended.
- Panel: `role="dialog"`, `aria-modal="true"`, `aria-label` = `chooseDate`; both attributes are dropped when `inline` (`primereact-10.9.9:components/lib/calendar/CalendarPanel.js` for React).
- Header buttons use locale ARIA keys `prevYear`, `nextYear`, `prevMonth`, `nextMonth`, `prevDecade`, `nextDecade`, `chooseMonth`, `chooseYear`; spinners use `prevHour`, `nextHour`, `prevMinute`, `nextMinute`, `prevSecond`, `nextSecond`, `am`, `pm` (PrimeReact adds `nextMilliSecond` / `prevMilliSecond`).
- Grid: day table has `role="grid"`, headers `scope="col"`, each cell an `aria-label`. PrimeVue and PrimeReact put `aria-selected` and `aria-disabled` on the day element (`primevue-4.5.5:packages/primevue/src/datepicker/DatePicker.vue`, `primereact-10.9.9:components/lib/calendar/Calendar.js`). A visually hidden `aria-live="polite"` region announces the selected day, month or year.
- Doc/source mismatch: the shared accessibility text for all three frameworks says the selected date gets `aria-selected` and column headers get `abbr`, but the PrimeNG component source contains neither attribute.
- Keyboard (from the accessibility docs): on the trigger, Space/Enter opens the popup and focuses the selected date or today. In the popup, Escape closes and refocuses the input; Tab / Shift+Tab move through the popup. In the date grid, Enter/Space select, close and return focus to the input; Up/Down move one week; Left/Right one day; Home/End first/last day of the current week; PageUp/PageDown previous/next month (month picker: year; year picker: decade); Shift+PageUp/PageDown previous/next year (no effect in month or year pickers). Header and footer buttons activate on Enter/Space. On the PrimeNG input, Down arrow opens the panel and Enter/Escape/Tab are handled (`primeng-21.1.9:packages/primeng/src/datepicker/datepicker.ts`).

## 9. Relationships

- Embeds: [InputText](inputtext.md) (`pcInputText`), Button (PrimeNG/PrimeVue navigation, today and clear buttons; PrimeReact trigger and button bar), Ripple, framework icons, an overlay container (PrimeNG motion overlay, PrimeVue `Portal`, PrimeReact `Portal` + `CSSTransition`).
- Wrapped by: [FloatLabel](floatlabel.md), [IftaLabel](iftalabel.md), [IconField](iconfield.md) (alternative to `showIcon` for decorative icons), [InputGroup](inputgroup.md) (addons around the input).
- Used with: InputMask (PrimeNG `pInputMask` directive for typed formats; PrimeReact has a built-in `mask`), [KeyFilter](keyfilter.md) for restricting typed characters.
- Alias chain / replacement: `Calendar` → DatePicker (PrimeNG renamed in v19, removed in v20; PrimeVue deprecated wrapper kept; PrimeReact still uses `Calendar`).
- Alternatives: Select for choosing from a fixed list of dates, InputNumber for numeric year entry, [AutoComplete](autocomplete.md) when suggestions are needed.
