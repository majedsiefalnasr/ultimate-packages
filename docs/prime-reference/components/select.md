# Select

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9 (as `Dropdown`)

## 1. Summary

Select is the single-choice dropdown input. A closed field shows the selected option label (or a placeholder, or an editable text box), an optional clear icon and a trigger icon. Opening it shows an overlay with an optional header (filter input), a scrollable list of options that can be grouped and templated, and optional virtual scrolling. It supports a checkmark selection style, a loading state, filled and outlined variants, small and large sizes and invalid state (`primeng-21.1.9:packages/primeng/src/select/select.ts`, `primevue-4.5.5:packages/primevue/src/select/Select.vue`, `primereact-10.9.9:components/lib/dropdown/Dropdown.js`).

In PrimeReact 10.9.9 the same component exists only under its legacy name `Dropdown`; PrimeVue 4.5.5 ships both `Select` and a deprecated `Dropdown` wrapper.

## 2. Names & status

- Canonical name: **Select** (PrimeNG and PrimeVue). Per `GLOSSARY.md`, "Dropdown" is a legacy alias and is not used as a primary name.
- PrimeNG: `p-select`, class `Select`; there is no `Dropdown` component. A leftover `.p-dropdown.ng-invalid.ng-dirty .p-dropdown-label.p-placeholder` selector remains in the PrimeNG style string (`primeng-21.1.9:packages/primeng/src/select/style/selectstyle.ts`).
- PrimeVue: `Select` is current; `Dropdown` is deprecated since v4. `Dropdown.vue` extends `Select` and logs `console.warn('Deprecated since v4. Use Select component instead.')` on mount; `Dropdown.d.ts` marks the component `@deprecated since v4. Use Select component instead.` and every `Dropdown*` type extends the matching `Select.*` type. `DropdownStyle` is `BaseStyle.extend({ name: 'dropdown' })` with no classes and an empty `DropdownClasses` enum (`primevue-4.5.5:packages/primevue/src/dropdown/Dropdown.vue`, `primevue-4.5.5:packages/primevue/src/dropdown/Dropdown.d.ts`, `primevue-4.5.5:packages/primevue/src/dropdown/style/DropdownStyle.js`, `primevue-4.5.5:packages/primevue/src/dropdown/style/DropdownStyle.d.ts`). `index.d.ts` still re-exports both (`primevue-4.5.5:packages/primevue/src/index.d.ts`). The `dropdown` pass-through key in the global PT options is marked `@deprecated` (`docs/prime-reference/foundations/primevue.md` §5).
- PrimeReact: only `Dropdown` exists (`components/lib/dropdown/`, `primereact/dropdown`); there is no `select` folder, doc folder or menu entry (`primereact-10.9.9:components/layout/menu.json`). Its CSS classes keep the `p-dropdown-*` names.
- Deprecated members:
  - PrimeNG `styleClass` is deprecated since v20.0.0 (use `class`) (`primeng-21.1.9:packages/primeng/src/select/select.ts`).
  - PrimeVue `inputClass`, `inputId`, `inputStyle` are deprecated since v4.0 (use `labelClass`, `labelId`, `labelStyle`); `panelClass` and `panelStyle` are deprecated since v4.0 (use `overlayClass`, `overlayStyle`) (`primevue-4.5.5:packages/primevue/src/select/Select.d.ts`).
  - PrimeReact `filterTemplate` and the `DropdownFilterOptions` interface are deprecated since v9.3.0 (`primereact-10.9.9:components/lib/dropdown/dropdown.d.ts`).
- Listed in the Form group of the PrimeNG and PrimeVue showcase menus as "Select" and in the PrimeReact menu as "Dropdown" (`primeng-21.1.9:apps/showcase/assets/data/menu.json`, `primevue-4.5.5:apps/showcase/assets/menu/menu.json`, `primereact-10.9.9:components/layout/menu.json`).

## 6. Usage guidance

- **Basic** — bind the selected value and supply an `options` array; `optionLabel` and `optionValue` map object fields, and plain primitive arrays need neither (`primeng-21.1.9:apps/showcase/doc/select/basic-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/BasicDoc.vue`, `primereact-10.9.9:components/doc/dropdown/basicdoc.js`).
- **Group** — nested option arrays become groups; name the group label field and the child collection field (`primeng-21.1.9:apps/showcase/doc/select/group-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/GroupDoc.vue`, `primereact-10.9.9:components/doc/dropdown/groupdoc.js`).
- **Template** — customise the selected value and each option (and group header); PrimeNG and PrimeVue use templates/slots, PrimeReact uses `valueTemplate` and `itemTemplate` (`primeng-21.1.9:apps/showcase/doc/select/template-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/TemplateDoc.vue`, `primereact-10.9.9:components/doc/dropdown/templatedoc.js`).
- **Filter** — the `filter` flag adds a search input to the overlay header (`primeng-21.1.9:apps/showcase/doc/select/filter-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/FilterDoc.vue`, `primereact-10.9.9:components/doc/dropdown/filterdoc.js`).
- **Custom filter** — PrimeNG replaces the built-in filter input with the `filter` template (`primeng-21.1.9:apps/showcase/doc/select/customfilter-doc.ts`); PrimeVue and PrimeReact have no dedicated demo (PrimeReact's `filterTemplate` is deprecated).
- **Checkmark** — shows a check icon on the selected option instead of a background highlight (`primeng-21.1.9:apps/showcase/doc/select/checkmark-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/CheckmarkDoc.vue`, `primereact-10.9.9:components/doc/dropdown/checkmarkdoc.js`).
- **Clear icon** — `showClear` adds a reset icon (`primeng-21.1.9:apps/showcase/doc/select/clearicon-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/ClearIconDoc.vue`, `primereact-10.9.9:components/doc/dropdown/clearicondoc.js`).
- **Editable** — the label becomes a text input so users can type a value that is not in the list (`primeng-21.1.9:apps/showcase/doc/select/editable-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/EditableDoc.vue`, `primereact-10.9.9:components/doc/dropdown/editabledoc.js`).
- **Loading state** — `loading` swaps the chevron for a spinner (`primeng-21.1.9:apps/showcase/doc/select/loadingstate-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/LoadingStateDoc.vue`, `primereact-10.9.9:components/doc/dropdown/loadingdoc.js`).
- **Virtual scroll** — for very large lists; PrimeNG uses `virtualScroll` plus `virtualScrollItemSize`, PrimeVue and PrimeReact pass `virtualScrollerOptions` to the VirtualScroller (`primeng-21.1.9:apps/showcase/doc/select/virtualscroll-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/VirtualScrollDoc.vue`, `primereact-10.9.9:components/doc/dropdown/virtualscrolldoc.js`).
- **Lazy virtual scroll** — loading items on demand while scrolling; PrimeNG pairs `lazy` with `onLazyLoad` (`primeng-21.1.9:apps/showcase/doc/select/lazyvirtualscroll-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/LazyVirtualScrollDoc.vue`, `primereact-10.9.9:components/doc/dropdown/lazyvirtualscrolldoc.js`).
- **Float label / Ifta label** — wrap the field in FloatLabel or IftaLabel; React has only the float label demo (`primeng-21.1.9:apps/showcase/doc/select/floatlabel-doc.ts`, `primeng-21.1.9:apps/showcase/doc/select/iftalabel-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/FloatLabelDoc.vue`, `primevue-4.5.5:apps/showcase/doc/select/IftaLabelDoc.vue`, `primereact-10.9.9:components/doc/dropdown/floatlabeldoc.js`).
- **Filled / Sizes / Fluid** — appearance variants; Sizes and Fluid have no React demo (`primeng-21.1.9:apps/showcase/doc/select/filled-doc.ts`, `primeng-21.1.9:apps/showcase/doc/select/sizes-doc.ts`, `primeng-21.1.9:apps/showcase/doc/select/fluid-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/FilledDoc.vue`, `primevue-4.5.5:apps/showcase/doc/select/SizesDoc.vue`, `primevue-4.5.5:apps/showcase/doc/select/FluidDoc.vue`, `primereact-10.9.9:components/doc/dropdown/filleddoc.js`).
- **Invalid / Disabled** — validation and disabled states (`primeng-21.1.9:apps/showcase/doc/select/invalid-doc.ts`, `primeng-21.1.9:apps/showcase/doc/select/disabled-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/InvalidDoc.vue`, `primevue-4.5.5:apps/showcase/doc/select/DisabledDoc.vue`, `primereact-10.9.9:components/doc/dropdown/invaliddoc.js`, `primereact-10.9.9:components/doc/dropdown/disableddoc.js`).
- **Forms** — Angular template-driven and reactive forms; PrimeVue uses `@primevue/forms` `Form` with a resolver and a dotted `name` (`primeng-21.1.9:apps/showcase/doc/select/templatedrivenforms-doc.ts`, `primeng-21.1.9:apps/showcase/doc/select/reactiveforms-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/FormsDoc.vue`). PrimeReact has no forms demo.
- **Style** (PrimeReact) — lists the legacy `p-dropdown-*` classes (`primereact-10.9.9:components/doc/dropdown/styledoc.js`).
- Required services/providers: none specific. PrimeNG relies on the global `providePrimeNG` configuration for `overlayAppendTo` and translation strings (`aria.listLabel`).

## 7. Accessibility

- All three document the same pattern: the field has `role="combobox"` with `aria-haspopup="listbox"` and `aria-expanded`; `aria-controls` points to the list id; `aria-activedescendant` tracks the focused option; the list is `role="listbox"` and each option is `role="option"` with `aria-label`, `aria-selected` and `aria-disabled` (`primeng-21.1.9:apps/showcase/doc/select/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/select/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/dropdown/accessibilitydoc.js`).
- Naming: `ariaLabel` / `ariaLabelledBy` (PrimeNG, PrimeReact) or `ariaLabel` / `ariaLabelledby` (PrimeVue). PrimeNG also has `ariaFilterLabel` for the filter input (`primeng-21.1.9:packages/primeng/src/select/select.ts`).
- PrimeNG: the label span carries `aria-required`, `aria-disabled` and `aria-controls` only while the overlay is open; the trigger is `role="button"` with `aria-label="dropdown trigger"`; the filter is `role="searchbox"` with `aria-owns` the list; the list `aria-label` comes from the `aria.listLabel` translation (`primeng-21.1.9:packages/primeng/src/select/select.ts`).
- PrimeVue: the combobox always sets `aria-controls` to the list id and adds `aria-invalid` when invalid; hidden `role="status" aria-live="polite"` regions announce the filter result count, the empty message and the selection message (`filterMessage`, `emptyMessage`, `selectionMessage` props) (`primevue-4.5.5:packages/primevue/src/select/Select.vue`).
- PrimeReact: focus goes to a visually hidden readonly `input` (`aria-haspopup="listbox"`, `aria-activedescendant="dropdownItem_<index>"`); the trigger is `role="button"` with `aria-expanded`; the clear icon has `aria-label` from the `clear` locale key and responds to Enter and Space (`primereact-10.9.9:components/lib/dropdown/Dropdown.js`, `primereact-10.9.9:components/lib/dropdown/DropdownPanel.js`, `primereact-10.9.9:components/lib/dropdown/DropdownItem.js`).
- Keyboard, closed: Tab moves focus; Space or Down opens and focuses the selected option (first when none); Up opens and focuses the selected option (last when none).
- Keyboard, open: Tab and Shift+Tab cycle focusable elements in the overlay; Enter or Space selects and closes; Escape closes and returns focus; Up and Down move; Home and End jump to first and last option (or move the cursor when editable); Left and Right move the cursor when editable; a printable character jumps to the option starting with the typed text when not editable. In the filter input, Enter and Escape close the overlay and refocus the field (NG and React docs); PrimeVue's doc lists a fuller filter-input table including Up, Down, Home, End and Tab.
- Doc/source mismatches: all three accessibility docs say `aria-autocomplete` is added when editable and mention a `filterInputProps` prop; neither string appears in the Select / Dropdown source of any framework.

## 8. Theming

- NG/Vue root class `p-select p-component p-inputwrapper` with modifiers `p-disabled`, `p-invalid`, `p-variant-filled`, `p-focus`, `p-inputwrapper-filled`, `p-inputwrapper-focus`, `p-select-open`, `p-select-fluid`, and size classes `p-select-sm p-inputfield-sm` / `p-select-lg p-inputfield-lg`. The label adds `p-placeholder` and `p-select-label-empty`; an option adds `p-select-option-selected`, `p-focus` and `p-disabled` (`primeng-21.1.9:packages/primeng/src/select/style/selectstyle.ts`, `primevue-4.5.5:packages/primevue/src/select/style/SelectStyle.js`). The 18 part classes are listed in Anatomy; the catalog lists them under `modules.select.style.classes` (PrimeNG) and `modules.selectstyle.enumerations.SelectClasses` (PrimeVue).
- Selected-option modifier differs: PrimeNG applies `p-select-option-selected` when selected and not `checkmark`; PrimeVue applies it when selected and `highlightOnSelect` (default `true`). PrimeNG's overlay also carries `p-component-overlay`, PrimeVue's does not.
- Source quirk (PrimeVue): the classes map defines the key `loadingicon` (`SelectStyle.js`), while `Select.vue` asks for `cx('loadingIcon')`; the catalog enum member is also `loadingicon` (`primevue-4.5.5:packages/primevue/src/select/style/SelectStyle.js`, `primevue-4.5.5:packages/primevue/src/select/Select.vue`). The `p-select-loading-icon` class has no rule in the shared CSS (`@primeuix/styles-2.0.3:dist/select/index.mjs`).
- Pass-through section keys: see Anatomy; PrimeNG exposes 27 typed keys (including `pcOverlay`, `pcFilterContainer`, `pcFilter`, `pcFilterIconContainer`), PrimeVue 29 (including `transition`, `hooks`), PrimeReact 27 (including `hooks`, `transition`, `tooltip`) (`primeng-21.1.9:packages/primeng/src/types/select/select.types.ts`, `primevue-4.5.5:packages/primevue/src/select/Select.d.ts`, `primereact-10.9.9:components/lib/dropdown/dropdown.d.ts`).
- Structural CSS: `@primeuix/styles-2.0.3:dist/select/index.mjs`. PrimeNG appends rules for `.p-select-label.p-placeholder` and for `ng-invalid.ng-dirty` (border colour and placeholder colour), using the `select.placeholder.color`, `select.invalid.border.color` and `select.invalid.placeholder.color` tokens.
- Design tokens (`@primeuix/themes-2.0.3:types/select/index.d.ts`): `root` (backgrounds including disabled and filled states, border colours, colours, placeholder colours, shadow, padding, radius, `focusRing`, `transitionDuration`, `sm` and `lg` sizes), `dropdown` (`width`, `color`), `overlay`, `list` (`padding`, `gap`, `header.padding`), `option`, `optionGroup`, `clearIcon.color`, `checkmark` (`color`, `gutterStart`, `gutterEnd`), `emptyMessage.padding`. ## 9. Relationships

- Embeds: IconField, InputIcon and InputText (filter, NG and Vue); Overlay (NG) or Portal (Vue, React); Scroller / VirtualScroller; Ripple (options); Tooltip (NG, React); Check and Blank icons for the checkmark style; PrimeReact embeds a CSSTransition.
- Shares the option, filter and keyboard model with [MultiSelect](multiselect.md) (multiple values) and [Listbox](listbox.md) (inline list).
- Related or alternative: AutoComplete (free-text with suggestions), CascadeSelect and TreeSelect (hierarchical single choice), SelectButton (few options as buttons).
- Embedded by: PrimeNG `paginator` and `table` import `primeng/select` (`primeng-21.1.9:packages/primeng/src/paginator/paginator.ts`, `primeng-21.1.9:packages/primeng/src/table/table.ts`); PrimeVue Paginator's rows-per-page and jump-to-page dropdowns and the DataTable column filter import `primevue/select` (`primevue-4.5.5:packages/primevue/src/paginator/RowsPerPageDropdown.vue`, `primevue-4.5.5:packages/primevue/src/paginator/JumpToPageDropdown.vue`, `primevue-4.5.5:packages/primevue/src/datatable/ColumnFilter.vue`); PrimeReact's Paginator rows-per-page and DataTable column filter use `Dropdown` (`primereact-10.9.9:components/lib/paginator/RowsPerPageDropdown.js`, `primereact-10.9.9:components/lib/datatable/ColumnFilter.js`).
- Alias chain: PrimeReact `Dropdown` ≙ PrimeNG/PrimeVue `Select`; PrimeVue `Dropdown` → extends `Select`.
