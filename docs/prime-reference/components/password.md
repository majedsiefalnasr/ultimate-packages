# Password

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

Password is a masked text input that can show a strength meter in a small popup while the user types, reveal the value through an eye toggle (`toggleMask`) and, in PrimeNG and PrimeVue, offer a clear icon (`showClear`). All three frameworks render an InputText (type `password`, switched to `text` when unmasked) inside a root element, plus an overlay that holds a meter bar and an info line. Strength is graded in three levels from two configurable regular expressions (`mediumRegex`, `strongRegex`). The overlay body can be customised with header, content and footer templates. PrimeNG additionally ships an attribute directive, `pPassword`, that decorates a native `input`.

## 2. Names & status

- Canonical name: **Password** in all three frameworks. There are no legacy aliases and the component is not deprecated. It is listed in the Form group of each showcase menu (`primeng-21.1.9:apps/showcase/assets/data/menu.json`, `primevue-4.5.5:apps/showcase/assets/menu/menu.json`, `primereact-10.9.9:components/layout/menu.json`).
- PrimeNG exports two things from `primeng/password`: the `Password` component (`p-password`) and the `PasswordDirective` (`[pPassword]`). The showcase never demonstrates the directive (`primeng-21.1.9:packages/primeng/src/password/password.ts`, `primeng-21.1.9:packages/primeng/src/password/public_api.ts`).
- Deprecated members:
  - PrimeNG `Password`: `maxLength` (since v20.0.0, use `maxlength`), `styleClass` (since v20.0.0, use `class`), `showTransitionOptions` and `hideTransitionOptions` (since v21.0.0, use `motionOptions`) (`primeng-21.1.9:packages/primeng/src/password/password.ts`).
  - PrimeVue: the `hideicon` and `showicon` slots (since v4.0, use `maskicon` and `unmaskicon`) (`primevue-4.5.5:packages/primevue/src/password/Password.d.ts`, `primevue-4.5.5:packages/primevue/src/password/Password.vue`).
  - PrimeReact: none found.

- Default regexes in all three frameworks: medium `^(((?=.*[a-z])(?=.*[A-Z]))|((?=.*[a-z])(?=.*[0-9]))|((?=.*[A-Z])(?=.*[0-9])))(?=.{6,})`, strong `^(?=.*[a-z])(?=.*[A-Z])(?=.*[0-9])(?=.{8,})`. Grading: strong match → level 3, else medium match → level 2, else any input → level 1 (weak), else 0 (back to the prompt text) (`primeng-21.1.9:packages/primeng/src/password/password.ts`, `primevue-4.5.5:packages/primevue/src/password/Password.vue`, `primereact-10.9.9:components/lib/password/Password.js`).
- Default label texts come from the framework locale: `Enter a password`, `Weak`, `Medium`, `Strong` (`primeng-21.1.9:packages/primeng/src/api/translationkeys.ts`, `primevue-4.5.5:packages/core/src/config/PrimeVue.js`, `primereact-10.9.9:components/lib/api/Locale.js`).
- PrimeVue slots `header`, `footer` and `content` receive no scope; the icon slots receive `toggleCallback` (mask/unmask) or `clearCallback` (clear) (`primevue-4.5.5:packages/primevue/src/password/Password.d.ts`).
- PrimeNG `PasswordDirective` inputs: `promptLabel` (`'Enter a password'`), `weakLabel`, `mediumLabel`, `strongLabel`, `feedback = true`, `showPassword` (setter switching the element `type`), `variant`, `fluid`, `size` (alias `pSize`). Its strength uses a score (weak below 30, medium 30 to below 80, strong 80 and above) rather than the regexes, and it builds its own panel element appended to `document.body` (`primeng-21.1.9:packages/primeng/src/password/password.ts`).
- Full API: catalog modules `password` (and `passwordstyle` for PrimeVue) (`docs/prime-reference/catalog/primeng.json`, `docs/prime-reference/catalog/primevue.json`, `docs/prime-reference/catalog/primereact.json`).

## 6. Usage guidance

- **Import** — a single import line per framework; PrimeNG needs `PasswordModule`, plus forms modules for binding (`primeng-21.1.9:apps/showcase/doc/password/import-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/ImportDoc.vue`, `primereact-10.9.9:components/doc/password/importdoc.js`).
- **Basic** — bind with `ngModel`, `v-model`, or `value` + `onChange`. The demos set `feedback` to false because the strength meter is on by default (`primeng-21.1.9:apps/showcase/doc/password/basic-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/BasicDoc.vue`, `primereact-10.9.9:components/doc/password/basicdoc.js`).
- **Meter** — while typing, the strength meter shows in a popup (`primeng-21.1.9:apps/showcase/doc/password/meter-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/MeterDoc.vue`, `primereact-10.9.9:components/doc/password/meterdoc.js`).
- **Locale** — translate the prompt and strength texts per component with the four label props, or globally through the locale configuration (`primeng-21.1.9:apps/showcase/doc/password/locale-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/LocaleDoc.vue`, `primereact-10.9.9:components/doc/password/localedoc.js`).
- **Toggle Mask** — `toggleMask` adds an eye icon that switches between masked and plain text (`primeng-21.1.9:apps/showcase/doc/password/togglemask-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/ToggleMaskDoc.vue`, `primereact-10.9.9:components/doc/password/togglemaskdoc.js`).
- **Clear Icon** — `showClear` adds a clear icon; PrimeReact has no demo or prop (`primeng-21.1.9:apps/showcase/doc/password/clearicon-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/ClearIconDoc.vue`).
- **Template** — header, content and footer customise the overlay; a custom content replaces the default meter. PrimeReact documents only header and footer in its demo, though `content` also exists as a prop (`primeng-21.1.9:apps/showcase/doc/password/template-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/TemplateDoc.vue`, `primereact-10.9.9:components/doc/password/templatedoc.js`).
- **Filled** — `variant="filled"` gives higher visual emphasis (`primeng-21.1.9:apps/showcase/doc/password/filled-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/FilledDoc.vue`, `primereact-10.9.9:components/doc/password/filleddoc.js`).
- **Float Label / Ifta Label** — wrap in FloatLabel or IftaLabel with a matching `inputId`; PrimeReact has no IftaLabel demo (`primeng-21.1.9:apps/showcase/doc/password/floatlabel-doc.ts`, `primeng-21.1.9:apps/showcase/doc/password/iftalabel-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/FloatLabelDoc.vue`, `primevue-4.5.5:apps/showcase/doc/password/IftaLabelDoc.vue`, `primereact-10.9.9:components/doc/password/floatlabeldoc.js`).
- **Sizes** — small and large alternatives through `size`; the PrimeNG demo also passes `type="text"` (`primeng-21.1.9:apps/showcase/doc/password/sizes-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/SizesDoc.vue`). PrimeReact has no size demo.
- **Fluid** — full container width (`primeng-21.1.9:apps/showcase/doc/password/fluid-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/FluidDoc.vue`). PrimeReact has no demo.
- **Invalid** — `invalid` marks failed validation; PrimeNG ties it to Angular forms, PrimeVue to any validation library (`primeng-21.1.9:apps/showcase/doc/password/invalid-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/InvalidDoc.vue`, `primereact-10.9.9:components/doc/password/invaliddoc.js`).
- **Disabled** — the field can be neither edited nor focused (`primeng-21.1.9:apps/showcase/doc/password/disabled-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/DisabledDoc.vue`, `primereact-10.9.9:components/doc/password/disableddoc.js`).
- **Forms** — PrimeNG shows reactive (`formControlName`) and template-driven (`ngModel` with `required`) forms; PrimeVue shows the PrimeVue Forms library with `name="password"`. The PrimeVue doc sentence says "InputText", an apparent copy-paste (`primeng-21.1.9:apps/showcase/doc/password/reactiveforms-doc.ts`, `primeng-21.1.9:apps/showcase/doc/password/templatedrivenforms-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/FormsDoc.vue`).
- **Style** — PrimeReact lists the structural classes in its doc (`primereact-10.9.9:components/doc/password/styledoc.js`).
- Required services: none for PrimeVue and PrimeReact beyond their normal config; PrimeNG's locale-driven labels read the I18N config (`primeng-21.1.9:packages/primeng/src/password/password.ts`).

## 7. Accessibility

- Label the field with `<label for>` plus `inputId` (React: `id` on the label target), or with `aria-labelledby` or `aria-label` (PrimeNG `ariaLabelledBy` / `ariaLabel`). The docs say the screen reader is told about strength changes through a section with `aria-live` while typing. Keyboard: Tab moves focus to the input; Escape hides the open strength meter (`primeng-21.1.9:apps/showcase/doc/password/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/password/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/password/accessibilitydoc.js`).
- Only PrimeVue implements the live announcement: a visually hidden `span` with `aria-live="polite"` repeats the info text, the overlay has `role="dialog"` and `aria-live="polite"`, and the input carries `aria-expanded`, `aria-controls` (the overlay id) and `aria-haspopup` (the value of `feedback`) (`primevue-4.5.5:packages/primevue/src/password/Password.vue`).
- PrimeNG and PrimeReact source contain no `aria-live`, so the documented announcement is not present there (`primeng-21.1.9:packages/primeng/src/password/password.ts`, `primereact-10.9.9:components/lib/password/Password.js`). The PrimeNG component sets `aria-label`, `aria-labelledBy` and `tabindex` on the input only.
- Toggle icon: PrimeReact gives the eye icons `role="switch"`, `tabIndex` (prop or `0`), an `aria-label` from the locale (`Show Password` / `Hide Password`), `aria-checked`, and toggles on Enter or Space. PrimeNG and PrimeVue render the toggle and clear icons as click-only elements without role or key handling (`primereact-10.9.9:components/lib/password/Password.js`, `primereact-10.9.9:components/lib/api/Locale.js`, `primeng-21.1.9:packages/primeng/src/password/password.ts`, `primevue-4.5.5:packages/primevue/src/password/Password.vue`).
- Escape handling: PrimeNG and PrimeVue react on `keyup` with `event.code === 'Escape'`; PrimeReact registers a global Escape listener with priority `ESC_KEY_HANDLING_PRIORITIES.PASSWORD` (700) so stacked overlays close in order (`primereact-10.9.9:components/lib/hooks/useGlobalOnEscapeKey.js`).

## 9. Relationships

- Embeds InputText in all three frameworks (see `inputtext.md`); PT is routed through `pcInputText` (PrimeReact merges input props through `input`).
- Overlay: PrimeNG embeds the Overlay component (`pcOverlay`); PrimeVue uses Portal plus a transition and `OverlayEventBus`; PrimeReact uses Portal, CSSTransition and `OverlayService`.
- PrimeReact `toggleMask` wraps the input in IconField and InputIcon (see `iconfield.md`).
- Composes with FloatLabel, IftaLabel (see `floatlabel.md`, `iftalabel.md`) and Fluid in PrimeNG and PrimeVue.
- Alternatives and neighbours: InputText (plain text), Divider (used in the PrimeNG template demo footer).
- No other component embeds Password in the source of the three archives (searched component folders for imports).
- PrimeNG alias chain: `p-password` component ↔ `[pPassword]` directive, which share class names and labels but differ in strength algorithm and overlay mechanism.
