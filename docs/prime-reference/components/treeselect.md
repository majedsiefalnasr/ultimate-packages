# TreeSelect

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

TreeSelect is a form field that picks one or several nodes from hierarchical data. A closed trigger shows the selection as a comma-separated label or as chips; opening it shows an overlay that hosts a Tree (with optional filter input) for choosing nodes in `single`, `multiple` or `checkbox` selection mode. Options are `TreeNode` objects, expansion is tracked automatically so the selected branches are open on first show, and a clear icon, loading state and lazy loading of children are supported (`primeng-21.1.9:packages/primeng/src/treeselect/treeselect.ts`, `primevue-4.5.5:packages/primevue/src/treeselect/TreeSelect.vue`, `primereact-10.9.9:components/lib/treeselect/TreeSelect.js`).

A key modelling difference: PrimeNG binds the selected **nodes** (`TreeNode` or `TreeNode[]`), whereas PrimeVue and PrimeReact bind a **key map** (a key string in PrimeReact single mode, `{ [key]: true }` in multiple mode, `{ [key]: { checked, partialChecked } }` in checkbox mode) (`primeng-21.1.9:apps/showcase/doc/treeselect/basic-doc.ts`, `primevue-4.5.5:packages/primevue/src/treeselect/TreeSelect.vue`, `primereact-10.9.9:components/lib/treeselect/treeselect.d.ts`).

## 2. Names & status

- Canonical name: **TreeSelect** in all three frameworks; no legacy aliases and no separate "Tree Select" entry.
- Listed in the Form group of all three showcase menus (Tree itself sits in the Data group) (`primeng-21.1.9:apps/showcase/assets/data/menu.json`, `primevue-4.5.5:apps/showcase/assets/menu/menu.json`, `primereact-10.9.9:components/layout/menu.json`).

The unnamed or named legacy `PrimeTemplate` fallback is marked with a `@deprecated Use "value" template instead` TODO (`primeng-21.1.9:packages/primeng/src/treeselect/treeselect.ts`).
- PrimeVue deprecated: slot `triggericon` (since v4.0; use `dropdownicon`) and slot `itemtogglericon` (since v4.0; use `itemtoggleicon`) (`primevue-4.5.5:packages/primevue/src/treeselect/TreeSelect.d.ts`).

## 6. Usage guidance

- **Basic** — bind through the form model with an `options` tree; single mode binds the node (NG) or its key (Vue, React), and the component is built on Tree so the data shape is the TreeNode API (`primeng-21.1.9:apps/showcase/doc/treeselect/basic-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/BasicDoc.vue`, `primereact-10.9.9:components/doc/treeselect/basicdoc.js`).
- **Multiple** — `selectionMode="multiple"`; by default a meta key is needed to add to the selection unless `metaKeySelection` is turned off; Vue/React bind a key-to-boolean map (`primeng-21.1.9:apps/showcase/doc/treeselect/multiple-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/MultipleDoc.vue`, `primereact-10.9.9:components/doc/treeselect/multipledoc.js`).
- **Checkbox** — `selectionMode="checkbox"` shows a checkbox per node; the showcase combines it with `display="chip"` (`primeng-21.1.9:apps/showcase/doc/treeselect/checkbox-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/CheckboxDoc.vue`, `primereact-10.9.9:components/doc/treeselect/checkboxdoc.js`).
- **Filter** — `filter` adds a search box; `filterBy` selects fields; `lenient` mode stops searching below a matching node (its descendants are all kept), `strict` continues into descendants (`primeng-21.1.9:apps/showcase/doc/treeselect/filter-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/FilterDoc.vue`, `primereact-10.9.9:components/doc/treeselect/filterdoc.js`).
- **Template** — NG/Vue only: value, header, footer, icon templates or slots for customising the field and the panel (`primeng-21.1.9:apps/showcase/doc/treeselect/template-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/TemplateDoc.vue`).
- **Lazy** — NG/Vue only: load children on node expand, driving the `loading` flag (the NG demo uses `loadingMode="icon"`) (`primeng-21.1.9:apps/showcase/doc/treeselect/lazy-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/LazyDoc.vue`).
- **Virtual scroll** — NG only: `virtualScroll` with `virtualScrollItemSize` for very large trees (`primeng-21.1.9:apps/showcase/doc/treeselect/virtualscroll-doc.ts`).
- **Controlled** — PrimeReact only: drive node expansion with `expandedKeys` and `onToggle` (`primereact-10.9.9:components/doc/treeselect/controlleddoc.js`).
- **Clear icon** — `showClear` shows a reset icon (`primeng-21.1.9:apps/showcase/doc/treeselect/clearicon-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/ClearIconDoc.vue`, `primereact-10.9.9:components/doc/treeselect/clearicondoc.js`).
- **Filled / Float label / Ifta label** — field-appearance variants; Ifta label is NG/Vue only (`primeng-21.1.9:apps/showcase/doc/treeselect/filled-doc.ts`, `primeng-21.1.9:apps/showcase/doc/treeselect/floatlabel-doc.ts`, `primeng-21.1.9:apps/showcase/doc/treeselect/iftalabel-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/FilledDoc.vue`, `primevue-4.5.5:apps/showcase/doc/treeselect/FloatLabelDoc.vue`, `primevue-4.5.5:apps/showcase/doc/treeselect/IftaLabelDoc.vue`, `primereact-10.9.9:components/doc/treeselect/filleddoc.js`, `primereact-10.9.9:components/doc/treeselect/floatlabeldoc.js`).
- **Sizes / Fluid** — `size` small/large and full-width `fluid`; NG/Vue only (`primeng-21.1.9:apps/showcase/doc/treeselect/sizes-doc.ts`, `primeng-21.1.9:apps/showcase/doc/treeselect/fluid-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/SizesDoc.vue`, `primevue-4.5.5:apps/showcase/doc/treeselect/FluidDoc.vue`).
- **Invalid / Disabled** — validation state and read-only/unfocusable state (`primeng-21.1.9:apps/showcase/doc/treeselect/invalid-doc.ts`, `primeng-21.1.9:apps/showcase/doc/treeselect/disabled-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/InvalidDoc.vue`, `primevue-4.5.5:apps/showcase/doc/treeselect/DisabledDoc.vue`, `primereact-10.9.9:components/doc/treeselect/invaliddoc.js`, `primereact-10.9.9:components/doc/treeselect/disableddoc.js`).
- **Forms** — Angular template-driven and reactive forms; PrimeVue uses `v-model` (`primeng-21.1.9:apps/showcase/doc/treeselect/templatedrivenforms-doc.ts`, `primeng-21.1.9:apps/showcase/doc/treeselect/reactiveforms-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/FormsDoc.vue`).
- **Style / Theming** — PrimeReact lists legacy structural classes and a styled/Tailwind theming page; PrimeVue has theming and Tailwind pages (`primereact-10.9.9:components/doc/treeselect/styledoc.js`, `primereact-10.9.9:components/doc/treeselect/theming/styleddoc.js`, `primereact-10.9.9:components/doc/treeselect/theming/tailwinddoc.js`, `primevue-4.5.5:apps/showcase/doc/treeselect/theming/index.vue`, `primevue-4.5.5:apps/showcase/doc/treeselect/theming/TailwindDoc.vue`).

## 7. Accessibility

- A visually hidden read-only `input` is the focus target: `role="combobox"`, `aria-haspopup="tree"`, `aria-expanded`, `aria-controls` pointing at the panel id (set only while open) and `aria-label` / `aria-labelledby` props. The trigger `div` is `role="button"` with `aria-haspopup="tree"` (`primeng-21.1.9:packages/primeng/src/treeselect/treeselect.ts`, `primevue-4.5.5:packages/primevue/src/treeselect/TreeSelect.vue`).
- PrimeReact deviates: its hidden input is `role="listbox"` (with `aria-haspopup="tree"`, `aria-expanded`, `aria-controls`) and the clear icon is focusable with Enter/Space support and a locale `clear` label (`primereact-10.9.9:components/lib/treeselect/TreeSelect.js`).
- The popup list is the embedded Tree: `role="tree"`, items `role="treeitem"` with `aria-label`, `aria-selected` (`aria-checked` in checkbox mode) and `aria-expanded`, group containers `role="group"`, plus implicit `aria-setsize` / `aria-posinset` / `aria-level`; checkbox and toggle icons are hidden from screen readers (`primeng-21.1.9:apps/showcase/doc/treeselect/accessibility-doc.ts`, `primevue-4.5.5:apps/showcase/doc/treeselect/AccessibilityDoc.vue`, `primereact-10.9.9:components/doc/treeselect/accessibilitydoc.js`).
- Keyboard, closed: Tab moves to the field; Space or Down opens the popup and focuses the selected node (else the first). Keyboard, open: Tab / Shift+Tab cycle focusable elements, Enter / Space select (single mode also closes), Escape closes and returns focus, Down / Up move between nodes, Right expands or enters the first child, Left collapses or goes to the parent. Filter input: Enter / Escape close the popup. Close button: Enter / Space / Escape close it (`primeng-21.1.9:apps/showcase/doc/treeselect/accessibility-doc.ts`).
- In source, PrimeNG and PrimeVue handle Down (open + focus a node), Space/Enter, Escape and Tab on the hidden input; hidden first/last sentinel spans keep Tab inside the overlay. PrimeVue and PrimeReact make Enter/Space toggle the overlay (close when already open), while PrimeNG Space/Enter only open it (`primeng-21.1.9:packages/primeng/src/treeselect/treeselect.ts`, `primevue-4.5.5:packages/primevue/src/treeselect/TreeSelect.vue`, `primereact-10.9.9:components/lib/treeselect/TreeSelect.js`).
- Doc/source mismatches: the accessibility docs describe a popup close button and a `filterInputProps` option, but the NG source renders no close button and has no `filterInputProps` input (the `closeicon` template is captured but unused); the close button exists only in PrimeReact's header (`primeng-21.1.9:packages/primeng/src/treeselect/treeselect.ts`, `primereact-10.9.9:components/lib/treeselect/TreeSelect.js`).
- PrimeReact header close button is labelled through `ariaLabel('close')` (`primereact-10.9.9:components/lib/treeselect/TreeSelect.js`).

## 9. Relationships

- Embeds: Tree (all three; data model is `TreeNode`, tree features such as filter, lazy loading, checkbox propagation and icons come from it), Overlay (NG) / Portal (Vue, React), Chip (NG and Vue chip display), Ripple (React close button; Vue registers the directive), Tooltip (React).
- Embedded by: no other Prime component in the reviewed sources.
- Related or alternative: MultiSelect and Select (flat option lists), CascadeSelect (hierarchical single choice using nested panels), TreeTable (tree-shaped tabular data), AutoComplete.
- Cross-category: Form component depending on Tree (Data category) and on Chip (Misc); the first-class Tree record should be read alongside this one for node, selection-key and filter semantics.
