# AutoComplete

**Category:** Form · **Frameworks:** PrimeNG 21.1.9 · PrimeVue 4.5.5 · PrimeReact 10.9.9

## 1. Summary

AutoComplete is a text input that asks the application for suggestions as the user types and shows them in an overlay list. The component does not filter data itself: it raises a "complete" event with the query and renders whatever `suggestions` array the application sets. It supports object options with a label field, grouped options, custom item templates, a dropdown button that opens the list without typing, forced selection, virtual scrolling and a `multiple` mode that renders the selection as removable chips. In PrimeNG and PrimeVue, `multiple` combined with `typeahead` set to false turns it into a free-text tags input, which is the official replacement for the removed or deprecated Chips/InputChips components.

## 2. Names & status

- Canonical name: **AutoComplete** (file `autocomplete`).
- PrimeNG: `AutoComplete` component, selectors `p-autoComplete`, `p-autocomplete`, `p-auto-complete`; stable. Deprecated inputs: `minLength` (since v20.0.0, use `minQueryLength`), `styleClass` (since v20.0.0, use `class`), `showTransitionOptions` / `hideTransitionOptions` (since v21.0.0, use `motionOptions`) (`primeng-21.1.9:packages/primeng/src/autocomplete/autocomplete.ts`).
- PrimeVue: `AutoComplete`; stable. Deprecated since v4.0: prop `loadingIcon` (use the `loader` slot), emits `item-select` / `item-unselect` (use `option-select` / `option-unselect`), slots `dropdownbutton` (use `dropdown`), `loadingicon` (use `loader`), `removetokenicon` (use `chipicon`) (`primevue-4.5.5:packages/primevue/src/autocomplete/AutoComplete.d.ts`).
- PrimeReact: `AutoComplete`; stable; no deprecated members found in `primereact-10.9.9:components/lib/autocomplete/autocomplete.d.ts`.
- Alias chain (tags input): PrimeNG removed `Chips` (deprecated v18, removed in v20) in favour of AutoComplete in multiple mode without typeahead (`primeng-21.1.9:apps/showcase/doc/migration/v20/removalsdoc.ts`, `primeng-21.1.9:apps/showcase/doc/migration/v19/deprecatedcomponentsdoc.ts`); PrimeVue keeps `Chips` → `InputChips` → AutoComplete as deprecated wrappers (`primevue-4.5.5:packages/primevue/src/chips/Chips.vue`, `primevue-4.5.5:packages/primevue/src/inputchips/InputChips.vue`); PrimeReact still ships a separate [Chips](chips.md) component.

## 4. Anatomy

PrimeNG/PrimeVue sections (PT keys, `primeng-21.1.9:packages/primeng/src/types/autocomplete/autocomplete.types.ts`, `primevue-4.5.5:packages/primevue/src/autocomplete/AutoComplete.d.ts`):

- **root** — wrapper `div`.
- **pcInputText** — the single-mode `InputText` (class `p-autocomplete-input`).
- **inputMultiple** — the multiple-mode `ul` (role `listbox`) holding **chipItem** `li`s, each with a **pcChip** (`Chip`) and **chipIcon** (remove icon), and the **inputChip** `li` with the typing input.
- **clearIcon**, **loader** (spinner), **dropdown** (button, PrimeVue also **dropdownIcon**).
- **overlay** (PrimeNG via **pcOverlay**; PrimeVue via `Portal` + **transition**) → **listContainer** → optional **pcScroller** / **virtualScroller** → **list** (`ul` role `listbox`) → **optionGroup** / **option** / **emptyMessage**.
- PrimeVue also lists hidden live-region sections `searchResultMessage`, `selectedMessage` in its PT type (the template binds `hiddenSearchResult` / `hiddenSelectedMessage`).

PrimeReact sections (`AutoCompletePassThroughOptions`, `primereact-10.9.9:components/lib/autocomplete/autocomplete.d.ts`): root, input, container (multiple `ul`), token, tokenLabel, removeTokenIcon, inputToken, loadingIcon, dropdownButton, panel, list, itemGroup, item, emptyMessage, footer, virtualScroller, tooltip, transition.

## 5. API highlights

- **Data flow (all):** `suggestions` (array set by the app in response to the complete event); PrimeNG output `completeMethod: AutoCompleteCompleteEvent` (`{ originalEvent, query }`); PrimeVue emit `complete`; PrimeReact callback `completeMethod(event: AutoCompleteCompleteEvent)`.
- **Option mapping:** PrimeNG `optionLabel`, `optionValue`, `optionDisabled` (string or function), `optionGroupLabel` (default `'label'`), `optionGroupChildren` (default `'items'`), `group: boolean = false`, `dataKey`; PrimeVue `optionLabel`, `optionDisabled`, `optionGroupLabel`, `optionGroupChildren` (string or Function), `dataKey` (no `optionValue`); PrimeReact `field`, `optionGroupLabel`, `optionGroupChildren`.
- **Query timing:** `delay: number = 300` (all); minimum characters — PrimeNG `minQueryLength` (`minLength = 1` deprecated), PrimeVue `minLength = 1`, PrimeReact `minLength = 1`; `completeOnFocus = false` (PrimeNG/PrimeVue).
- **Dropdown:** `dropdown = false`, `dropdownMode = 'blank'` (`'blank' | 'current'`), `dropdownIcon`; PrimeNG/PrimeReact `dropdownAriaLabel`; PrimeReact `dropdownAutoFocus = true`.
- **Selection rules:** `forceSelection = false`; `multiple = false`; PrimeNG `unique = true`; PrimeReact `selectionLimit`; PrimeNG/PrimeVue `autoOptionFocus = false`, `selectOnFocus = false`, `focusOnHover = true`, PrimeNG/PrimeReact `autoHighlight = false`.
- **Tags-input mode:** `typeahead: boolean = true` (PrimeNG/PrimeVue). With `multiple` and `typeahead=false`, Enter adds the typed text as a chip (`primevue-4.5.5:packages/primevue/src/autocomplete/AutoComplete.vue`); PrimeNG adds `addOnBlur = false`, `addOnTab = false`, `separator: string | RegExp` and output `onAdd` (`primeng-21.1.9:packages/primeng/src/autocomplete/autocomplete.ts`).
- **Overlay:** PrimeNG `appendTo` signal (falls back to `PrimeNG.overlayAppendTo`, default `'self'`), `overlayOptions`, `motionOptions`, `scrollHeight = '200px'`, `panelStyle`/`panelStyleClass`; PrimeVue `appendTo = 'body'`, `scrollHeight = '14rem'`, `overlayClass`/`overlayStyle` (`panelClass`/`panelStyle` also present); PrimeReact `appendTo` (defaults to `document.body`), `scrollHeight = '200px'`, `transitionOptions`, `panelClassName`/`panelStyle`.
- **Virtual scroll / lazy:** PrimeNG `virtualScroll`, `virtualScrollItemSize`, `virtualScrollOptions`, `lazy`, output `onLazyLoad`; PrimeVue `virtualScrollerOptions`; PrimeReact `virtualScrollerOptions`.
- **Messages:** `showEmptyMessage` (PrimeNG/PrimeVue default `true`, PrimeReact default `false`), `emptyMessage` (PrimeNG/PrimeReact) / `emptySearchMessage` (PrimeVue); `searchMessage = '{0} results are available'`, `selectionMessage = '{0} items selected'`, `emptySelectionMessage = 'No selected item'` (PrimeNG/PrimeVue).
- **Clear:** `showClear = false` (PrimeNG/PrimeVue) with output/emit `onClear` / `clear`; PrimeReact has no clear button but declares an `onClear` callback.
- **Events:** PrimeNG `onSelect`, `onUnselect`, `onAdd`, `onFocus`, `onBlur`, `onDropdownClick`, `onClear`, `onInputKeydown`, `onKeyUp`, `onShow`, `onHide`, `onLazyLoad`; PrimeVue `option-select`, `option-unselect`, `dropdown-click`, `clear`, `focus`, `blur`, `change`, `before-show`, `before-hide`, `show`, `hide`, `update:modelValue`, `value-change`; PrimeReact `onChange`, `onSelect`, `onUnselect`, `onDropdownClick`, `onClear`, `onFocus`, `onBlur`, `onShow`, `onHide`, `onKeyUp`, `onKeyPress`, `onClick`, `onDblClick`, `onContextMenu`, `onMouseDown`.
- **Templates:** PrimeNG `item`, `group`, `selecteditem`, `header`, `footer`, `empty`, `loader`, `removeicon`, `loadingicon`, `clearicon`, `dropdownicon`; PrimeVue slots `option`, `optiongroup`, `chip`, `chipicon`, `header`, `footer`, `empty`, `content`, `loader`, `dropdown`, `dropdownicon`, `clearicon`; PrimeReact `itemTemplate`, `optionGroupTemplate`, `selectedItemTemplate`, `panelFooterTemplate`, icon props `dropdownIcon`, `loadingIcon`, `removeTokenIcon`.
- **Methods:** PrimeReact `focus()`, `getElement()`, `getInput()`, `getOverlay()`, `getVirtualScroller()`, `hide()`, `search(event, query, source)`, `show()` (catalog `docs/prime-reference/catalog/primereact.json`).
- **Shared form inputs:** PrimeNG/PrimeVue `size: 'small' | 'large'`, `variant`, `fluid`, `invalid`, `disabled`, `name`, `required` (PrimeNG); PrimeReact `variant`, `invalid`, `disabled`, `required`, `tooltip`, `tooltipOptions`, `size: number` (native input size).

## 7. Accessibility

- Input: `role="combobox"`, `aria-autocomplete="list"`, `aria-expanded`, `aria-controls` (the list id while open), `aria-activedescendant` (focused option); label via `<label for=inputId>`, `ariaLabel` or `ariaLabelledBy` / `ariaLabelledby` / `aria-labelledby`. PrimeVue and PrimeReact add `aria-haspopup="listbox"`; the PrimeNG docs mention `aria-haspopup` but the PrimeNG input template does not bind it (`primeng-21.1.9:packages/primeng/src/autocomplete/autocomplete.ts`, `primeng-21.1.9:apps/showcase/doc/autocomplete/accessibility-doc.ts`, `primevue-4.5.5:packages/primevue/src/autocomplete/AutoComplete.vue`, `primereact-10.9.9:components/lib/autocomplete/AutoComplete.js`).
- Popup: `ul` with `role="listbox"`, options `role="option"` with `aria-selected`, `aria-disabled`, `aria-setsize`, `aria-posinset` (PrimeNG/PrimeVue); PrimeReact items set `role="option"` and `aria-selected` (`primereact-10.9.9:components/lib/autocomplete/AutoCompletePanel.js`).
- Multiple mode: the chip list is a horizontal `listbox` (`aria-orientation="horizontal"`) and each chip an `option` labelled with its value (PrimeNG/PrimeVue); PrimeReact's container `ul` has no role in source although the doc describes one (`primereact-10.9.9:components/doc/autocomplete/accessibilitydoc.js`).
- Live regions: hidden `role="status" aria-live="polite"` spans announce `searchMessage` / `selectionMessage` (PrimeNG/PrimeVue).
- Keyboard (all three docs): Tab, Up/Down Arrow, Enter, Home, End, Escape on the input; Backspace deletes the last chip and Left Arrow moves to chips when the input is empty; on a focused chip Left/Right Arrow move and Backspace removes. PrimeReact's key handler covers Down, Up, Enter, Escape, Tab and Backspace (`primereact-10.9.9:components/lib/autocomplete/AutoComplete.js`, `primevue-4.5.5:apps/showcase/doc/autocomplete/AccessibilityDoc.vue`).
- Locale: PrimeReact reads `localeOption('clear')` (chip remove icon label), `'choose'` (dropdown label fallback after `dropdownAriaLabel` and `placeholder`) and `'emptyMessage'`.
