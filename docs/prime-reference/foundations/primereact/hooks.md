# PrimeReact 10.9.9 — hooks

PrimeReact ships a set of general-purpose React hooks in `components/lib/hooks`, published as `primereact/hooks` and re-exported from the all-in-one bundle. Components use several of them internally (event binding, overlays, style injection, prop merging); others are utilities offered only to applications.

Sources: `primereact-10.9.9:components/lib/hooks/Hooks.js`, `primereact-10.9.9:components/lib/hooks/hooks.d.ts`, `primereact-10.9.9:components/lib/primereact.all.js`.

## Exports

`Hooks.js` exports exactly these names: `ESC_KEY_HANDLING_PRIORITIES`, `useClickOutside`, `useCounter`, `useDebounce`, `useDisplayOrder`, `useEventListener`, `useFavicon`, `useGlobalOnEscapeKey`, `useIntersectionObserver`, `useInterval`, `useLocalStorage`, `useMatchMedia`, `useMergeProps`, `useMountEffect`, `useMouse`, `useMove`, `useOverlayListener`, `useOverlayScrollListener`, `usePrevious`, `useResizeListener`, `useSessionStorage`, `useStorage`, `useStyle`, `useTimeout`, `useUnmountEffect`, `useUpdateEffect` (`primereact-10.9.9:components/lib/hooks/Hooks.js`).

The folder also contains `useLocale.js`, which is **not** exported by `Hooks.js`, not declared in `hooks.d.ts`, and not imported anywhere else in `components/lib`. It is dead code: a context-aware copy of the locale API with its own duplicated `en` table (`primereact-10.9.9:components/lib/hooks/useLocale.js`).

Showcase documentation exists for 18 hooks under `components/doc/hooks/` (`useclickoutside`, `usecounter`, `usedebounce`, `useeventlistener`, `usefavicon`, `useintersectionobserver`, `useinterval`, `usemounteffect`, `usemouse`, `usemove`, `useoverlaylistener`, `useoverlayscrolllistener`, `useprevious`, `useresizelistener`, `usestorage`, `usetimeout`, `useunmounteffect`, `useupdateeffect`). `useDisplayOrder`, `useGlobalOnEscapeKey`, `useMatchMedia`, `useMergeProps` and `useStyle` have no showcase page (`primereact-10.9.9:components/doc/hooks/`, `primereact-10.9.9:pages/hooks/`).

## Signatures and behaviour

Signatures below are copied from `hooks.d.ts`; behaviour notes come from the implementation file named in each row.

### Lifecycle hooks

| Hook               | Declared signature                                                                 | Behaviour                                                                                         | Source                |
| ------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------- |
| `useMountEffect`   | `useMountEffect(effect: React.EffectCallback): void`                               | Runs the callback once after the first render; a ref guard prevents re-runs. Returns its cleanup. | `useMountEffect.js`   |
| `useUpdateEffect`  | `useUpdateEffect(effect: React.EffectCallback, deps?: React.DependencyList): void` | Skips the first render, then behaves like `useEffect` with the given deps.                        | `useUpdateEffect.js`  |
| `useUnmountEffect` | `useUnmountEffect(effect: React.EffectCallback): void`                             | `useEffect(() => fn, [])` — the callback runs only on unmount.                                    | `useUnmountEffect.js` |
| `usePrevious`      | `usePrevious<V>(value: V): V \| undefined`                                         | Returns the value from the previous render (stored in a ref inside an effect).                    | `usePrevious.js`      |

### Event and overlay hooks

| Hook                       | Declared signature                                                                                                           | Behaviour                                                                                                                                                                                                                                                                                                                                                                                                                              | Source                        |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `useEventListener`         | `useEventListener(options: EventOptions): any[]`                                                                             | Implementation `({ target = 'document', type, listener, options, when = true })`. Returns `[bind, unbind]`; nothing is attached until `bind()` is called. `bind({ target, when })` can retarget. Targets resolve through `DomHandler.getTargetElement`. Rebinds when the listener or options change.                                                                                                                                   | `useEventListener.js`         |
| `useResizeListener`        | `useResizeListener(options: ResizeEventOptions): any[]`                                                                      | `useEventListener` preset for `window` `resize`; returns `[bind, unbind]`.                                                                                                                                                                                                                                                                                                                                                             | `useResizeListener.js`        |
| `useOverlayScrollListener` | `useOverlayScrollListener(options: EventOptions): any[]`                                                                     | Attaches a `scroll` listener to every scrollable parent of `target` (`DomHandler.getScrollableParents`), plus `window` when `hideOverlaysOnDocumentScrolling` is on (context, else static `PrimeReact`) or `document.body` otherwise. Returns `[bind, unbind]`.                                                                                                                                                                        | `useOverlayScrollListener.js` |
| `useOverlayListener`       | `useOverlayListener(options: OverlayEventOptions): any[]`                                                                    | Implementation `({ target, overlay, listener, when = true, type = 'click' })`. Combines a window click listener, window resize, `orientationchange` and overlay scroll. The listener receives `(event, { type, valid })`; an outside click is `valid` when it is not a right-click and lands outside both target and overlay; resize is `valid` unless the device is a touch device. Returns `[bind, unbind]`.                         | `useOverlayListener.js`       |
| `useClickOutside`          | `useClickOutside(ref: React.RefObject<Element>, callback: any): void`                                                        | Binds `mousedown` and `touchstart` on the document and calls `callback(event)` when the event target is outside `ref.current`. The implementation returns `[ref, callback]` although the type says `void`.                                                                                                                                                                                                                             | `useClickOutside.js`          |
| `useGlobalOnEscapeKey`     | `useGlobalOnEscapeKey(props: { callback: (event: KeyboardEvent) => void; when: boolean; priority: [number, number] }): void` | Registers the callback in a module-level map keyed by `[primary, secondary]` priority. One document `keydown` listener exists while any callback is registered; on `event.code === 'Escape'` only the callback with the highest primary, then highest secondary, priority runs. Registering a duplicate priority throws `Unexpected: global esc key listener with priority [${primaryPriority}, ${secondaryPriority}] already exists.` | `useGlobalOnEscapeKey.js`     |

`ESC_KEY_HANDLING_PRIORITIES` (bigger is handled first): `SIDEBAR: 100`, `SLIDE_MENU: 200`, `DIALOG: 300`, `IMAGE: 400`, `MENU: 500`, `OVERLAY_PANEL: 600`, `PASSWORD: 700`, `CASCADE_SELECT: 800`, `SPLIT_BUTTON: 900`, `SPEED_DIAL: 1000`, `TOOLTIP: 1200` (`primereact-10.9.9:components/lib/hooks/useGlobalOnEscapeKey.js`). Components pass a pair such as `[ESC_KEY_HANDLING_PRIORITIES.DIALOG, displayOrder]`, where the second number usually comes from `useDisplayOrder`.

Option types declared in `hooks.d.ts`: `EventOptions` (`target?: 'document' | 'window' | React.Ref<HTMLElement>`, `type?: string`, `listener?(event: Event): void`, `options?: any`, `when?: boolean`); `OverlayListenerOptions` (`type: 'scroll' | 'outside' | 'resize' | 'orientationChange'`, `valid: boolean`); `OverlayEventOptions` (`target?`, `overlay?`, `listener?(event: Event, options?: OverlayListenerOptions): void`, `when?: boolean`); `ResizeEventOptions` (`listener?(event: Event): void`, `when?: boolean`). Components pass the Escape priority as e.g. `[ESC_KEY_HANDLING_PRIORITIES.SIDEBAR, sidebarDisplayOrder]` (`primereact-10.9.9:components/lib/sidebar/Sidebar.js`). Note that the runtime reports `type: 'orientationchange'` (lower case) while the type union spells `'orientationChange'` (`primereact-10.9.9:components/lib/hooks/useOverlayListener.js`, `primereact-10.9.9:components/lib/hooks/hooks.d.ts`).

| `useTimeout`  | `useTimeout(fn: any, delay?: number, when?: boolean): any[]`                                      | Defaults `delay = 0`, `when = true`. Starts a `setTimeout` while `when` is true, always calls the latest `fn` (ref), clears on unmount. Returns `[clear]`. | `useTimeout.js`  |
| `useInterval` | `useInterval(fn: any, delay?: number, when?: boolean): any[]`                                     | Same shape with `setInterval`. Returns `[clear]`.                                                                                                          | `useInterval.js` |

| `useMouse`                | `useMouse(): MouseDataOptions`                                                                              | Returns `{ ref, x, y, reset }`. When `ref` is attached, coordinates are relative to that element; otherwise document client coordinates. Values are rounded and clamped at 0.                                                                                                                            | `useMouse.js`                |
| `useMove`                 | `useMove(mode: 'horizontal' \| 'vertical' \| 'both', initialValue: MousePositionOptions): MouseMoveOptions` | The implementation takes **one object**: `useMove({ mode = 'both', initialValue = { x: 0, y: 0 } })`, so the declared positional signature is wrong. | `useIntersectionObserver` | `useIntersectionObserver(ref: React.RefObject<Element>, options?: IntersectionObserverInit): boolean`       | Returns whether the element currently intersects (`entry.isIntersecting`).                                                                                                                                                                                                                               | `useIntersectionObserver.js` |
| `useMatchMedia`           | `useMatchMedia(query: string, when?: boolean): boolean`                                                     | Returns `window.matchMedia(query).matches` and updates on `change`; `when` defaults to `true`.                                                                                                                                                                                                           | `useMatchMedia.js`           |

### Styling and prop hooks

| Hook            | Declared signature                                                        | Behaviour                                                                                                                                                                                                                                                                                                                                                                                                                                           | Source             |
| --------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| `useStyle`      | `useStyle(css: string, options?: UseStyleOptions): StyleOptions`          | Implementation options ``{ document, manual = false, name = `style_${++_id}`, id, media }``. `load()`finds or creates`<style data-primereact-style-id="{name}">`inside`context.styleContainer`or`document.head`, applies the nonce (`context.nonce`or`PrimeReact.nonce`) and sets the text. Returns `{ id, name, update, unload, load, isLoaded }`. Loads automatically unless `manual`; automatic unload on unmount is commented out as a `@todo`. | `useStyle.js`      |
| `useMergeProps` | `useMergeProps(): (args: object[], options?: any) => object \| undefined` | Returns `(...props) => mergeProps(props, context?.ptOptions)`, so the provider's `ptOptions.classNameMergeFunction` (for example tailwind-merge) is applied. The returned function is variadic at runtime even though the type shows an array parameter.                                                                                                                                                                                            | `useMergeProps.js` |

Declared result types: `UseStyleOptions` (`document?: Document`, `immediate: boolean`, `manual: boolean`, `name: string`, `media: string`); `StyleOptions` (`name: string`, `css: React.RefObject<string>`, `load: () => void`, `unload: () => void`, `isLoaded: boolean`); `MousePositionOptions` (`x: number`, `y: number`); `MouseDataOptions extends MousePositionOptions` (adds `reset: () => void`, `ref: React.RefObject<HTMLElement>`); `MouseMoveOptions extends MouseDataOptions` (adds `active: boolean`). The types and runtime drift for `useStyle`: `immediate` is declared but never read, `css` is declared but not returned, and the returned `id` and `update` are undeclared (`primereact-10.9.9:components/lib/hooks/hooks.d.ts`, `primereact-10.9.9:components/lib/hooks/useStyle.js`).

All behaviour paths above are relative to `primereact-10.9.9:components/lib/hooks/`.
