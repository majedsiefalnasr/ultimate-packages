### Locale

`Locale.js` keeps a module-level `locales` map seeded with a complete `en` entry; other languages are added at runtime (`primereact-10.9.9:components/lib/api/Locale.js`). Declared signatures (`primereact-10.9.9:components/lib/api/api.d.ts`):

```ts
export declare function locale(locale: string): { locale: string; options: object };
export declare function addLocale(locale: string, options: LocaleOptions): void;
export declare function updateLocaleOption<Key extends keyof LocaleOptions>(
  key: Key,
  value: Key extends keyof LocaleOptions ? LocaleOptions[Key] : any,
  locale: string
): void;
export declare function updateLocaleOption<Key extends string>(
  key: Key,
  value: Key extends keyof LocaleOptions ? LocaleOptions[Key] : any,
  locale: string
): void;
export declare function updateLocaleOptions(options: object, locale: string): void;
export declare function localeOption<Key extends keyof LocaleOptions>(
  key: Key,
  locale: string
): LocaleOptions[Key];
export declare function localeOption(key: string, locale: string): any;
export declare function localeOptions(locale: string): object;
export declare function ariaLabel(ariaKey: string, options: any): string;
```

Behaviour:

- `locale(key)` sets the **static** `PrimeReact.locale` (not the context) and returns `{ locale, options }`.
- `addLocale(key, options)` stores `{ ...locales.en, ...options }`, so missing keys fall back to English.
- `updateLocaleOption(key, value, locale)` and `updateLocaleOptions(options, locale)` patch an existing locale.
- `localeOption(key, locale)` reads one key, defaulting to `PrimeReact.locale`; an unknown locale throws `The ${key} option is not found in the current locale('${_locale}').`
- `ariaLabel(ariaKey, options)` reads `aria[ariaKey]` from the active locale and replaces each `{name}` placeholder with `options.name`.
- Every function rejects keys or locale names containing `__proto__` or `prototype` (`Unsafe locale detected`, `Unsafe key detected`, `Unsafe ariaKey detected`).
- Components read the locale from `context.locale` when a provider is present and pass it to `localeOption`; the provider also mirrors its locale into `PrimeReact.locale`.

`LocaleOptions` declares the text keys (filter labels such as `startsWith`, `dateIs`, `matchAll`; dialog/upload labels such as `accept`, `reject`, `choose`, `upload`, `cancel`; calendar data `dayNames`, `dayNamesShort`, `dayNamesMin`, `monthNames`, `monthNamesShort`, `firstDayOfWeek`, `dateFormat`, `today`, `weekHeader`, `am`, `pm`, …; password strength `weak`, `medium`, `strong`, `passwordPrompt`; `emptyFilterMessage`, `emptyMessage`) and a nested `aria` object with keys such as `trueLabel`, `falseLabel`, `nullLabel`, `star`, `stars`, `selectAll`, `close`, `pageLabel`, `otpLabel`, `rowsPerPageLabel`, `zoomImage`, `listLabel`. The runtime `en` table has more keys than the type, for example `emptySearchMessage`, `emptySelectionMessage`, `searchMessage: '{0} results are available'`, `selectionMessage: '{0} items selected'`, `fileChosenMessage`, `noFileChosenMessage`, `showMonthAfterYear: false`, and aria keys `passwordShow`, `passwordHide`, `expandLabel`, `collapseLabel`, `selectLabel`, `unselectLabel`, `removeLabel` (`primereact-10.9.9:components/lib/api/Locale.js`, `primereact-10.9.9:components/lib/api/api.d.ts`). Ready-made translations are not in the archive; the showcase points to the external PrimeLocale repository (`primereact-10.9.9:components/doc/configuration/locale/repositorydoc.js`).

### FilterService

A plain object (`primereact-10.9.9:components/lib/api/FilterService.js`) with:

- `filter(value, fields, filterValue, filterMatchMode, filterLocale)` — returns the items of `value` that match. String items are tested directly; object items are tested field by field through `ObjectUtils.resolveFieldData` (dot paths supported) and kept on the first matching field.
- `filters` — the built-in rules: `startsWith`, `contains`, `notContains`, `endsWith`, `equals`, `notEquals`, `in`, `notIn`, `between`, `lt`, `lte`, `gt`, `gte`, `dateIs`, `dateIsNot`, `dateBefore`, `dateAfter`. Text rules remove accents (`ObjectUtils.removeAccents`) and compare with `toLocaleLowerCase(filterLocale)`. Most rules return `true` for an empty filter and `false` for a `null` value. `between` expects a two-element array and compares `Date`s by `getTime()`; `dateIs` / `dateIsNot` compare `toDateString()`.
- `register(rule, fn)` — adds or replaces `filters[rule]`; DataTable's `custom` match mode uses this.

Declared as `namespace FilterService { function filter(value: any, fields: string[], filterValue: any, filterMatchMode: string, filterLocale?: string): any[]; const filters: {…}; function register(rule: string, fn: (...arg: any[]) => boolean): void; }`. The declared `filters` type omits `notIn` (`primereact-10.9.9:components/lib/api/api.d.ts`). A unit test exists at `primereact-10.9.9:components/lib/api/test/FilterService.spec.js`.

## CSSTransition

`primereact/csstransition` wraps `CSSTransition` from `react-transition-group` (`primereact-10.9.9:components/lib/csstransition/CSSTransition.js`):

- Props are merged with `CSSTransitionBase.defaultProps` (`__TYPE: 'CSSTransition'`, `children: undefined`) (`primereact-10.9.9:components/lib/csstransition/CSSTransitionBase.js`).
- Animation is **disabled** when `props.disabled`, `props.options.disabled`, `context.cssTransition === false` or the static `PrimeReact.cssTransition` is false. Disabled transitions render `props.children` when `in` is true and `null` otherwise, and still fire the enter (`onEnter`, `onEntering`, `onEntered`) or exit callbacks synchronously on each change of `in`, so components relying on them (focus, z-index) keep working.
- Each lifecycle callback calls the component's handler first and then the user's handler from `props.options` (components expose this as a `transitionOptions` prop).
- `classNames`, `timeout` and `unmountOnExit` can be overridden by `props.options`; `nodeRef`, `in`, `appear` and the callbacks cannot.
- Type: `CSSTransitionProps<Ref> = ReactCSSTransitionProps<Ref> & { disabled?: boolean | undefined }` (`primereact-10.9.9:components/lib/csstransition/csstransition.d.ts`).

Styled-mode class names for the two standard transitions (`p-connected-overlay-*` for overlays, `p-toggleable-content-*` for collapsible content) live in `commonStyle` in `ComponentBase.js`; the Tailwind preset supplies equivalents in `TRANSITIONS` (`primereact-10.9.9:components/lib/componentbase/ComponentBase.js`, `primereact-10.9.9:components/lib/passthrough/tailwind/index.js`).
