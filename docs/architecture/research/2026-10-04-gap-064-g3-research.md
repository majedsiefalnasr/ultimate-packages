# GAP-064 G3 research — hand-written-CSS components (46 Angular / 48 Vue)

**Date:** 2026-10-04
**Evidence gathered at:** `main` `fa5c150` (after GAP-064 Tranche 1). The evidence comes from a static scan of `packages/{ng,vue}/src` and a runtime resolution of `dt()` paths against the built `@ultimate/themes` / `@ultimate/uix-styled`.
**Baseline (ADR-048):**

- PrimeNG 21.1.9 and PrimeVue 4.5.5, extracted from the pinned tarballs in `.vendor-cache/`;
- `@primeuix/styles` 2.0.3 (`.vendor-extracted/uix-styles-full/src/<key>/index.ts`);
- `@primeuix/themes` 2.0.3.

**Status:** research record.

- §1–§10 are the Research + Architecture Decision Brief as presented.
- §11 records the decisions the user took on it (2026-10-04).
- No implementation; GAP-064 stays PARTIAL.

**Markers:** ✅ = confirmed by evidence; 🔶 = hypothesis to verify at Spec time.

## 1. Executive summary

- ✅ G3 is exactly **46 Angular** and **48 Vue** components, under **48 Aura keys**. Vue's four Accordion directories share the `accordion` key. InlineMessage and OrganizationChart exist only in Vue.
- ✅ All 48 keys have upstream structural CSS (`@primeuix/styles/<key>`) and a registered Aura module.
- ✅ Every token those upstream styles reference already exists in the Ultimate preset, except for 6 that resolve to nothing upstream as well (§6). **G3 needs no new preset modules.**
- ✅ G3 is a component/CSS problem, not a token problem. Three things stand in the way:
  1. 38 of 94 components register a hyphenated key (`progress-bar`, `tiered-menu`, …) — the ADR-051 rule applies.
  2. 20 of 94 root DOM classes differ from the upstream names (`u-progress-bar` vs `p-progressbar`), and many sub-element names differ too.
  3. Many upstream rule groups target features Ultimate does not render.
- ✅ Classification: **34 Direct, 55 Adapted, 5 Ultimate-specific, 0 not tokenizable.** This classification is research guidance; each component is re-reviewed in its family Spec.
- ✅ No G3 component has screenshot coverage today.

## 4. CSS / token comparison

**Classification rules:**

- **Direct:** root class equals the upstream name, exact match ≥ 70%, and no known structural difference.
- **Adapted:** the root name differs, exact match is < 70%, or there is a known DOM/behaviour difference (§5).
- **Ultimate-specific:** match ≤ ~15% (normalized) with an Ultimate-only structure.

**Result:**

- **Direct (34):** card, fieldset, inplace, panel, toolbar, breadcrumb, dock, steps, tabs, tieredmenu, avatar, chip, knob, overlaybadge, tag, terminal, carousel — each ×2.
- **Ultimate-specific (5):** galleria ×2 (7/41), dataview ×2 (0/7; no header/content/footer/paginator wrappers), Vue organizationchart (0/11).
- **Adapted (55):** all the rest.
- **Not tokenizable:** 0.

✅ **Token references.** Upstream styles reference own-key tokens plus a few semantic ones (speeddial 1, splitter 1, stepper 4, toast 3), and all of these resolve. The only cross-component reference is `contextmenu` → `tieredmenu.submenu.mobile.indent`, which belongs to the mobile mode Ultimate does not render.
