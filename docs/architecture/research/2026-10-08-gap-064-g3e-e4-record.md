**Harness notes (Step 3/4; recorded, not parity differences):**

- **OrganizationChart reference template:** PrimeVue renders node content only through the default slot. The plan's template passed none, so the Prime nodes were empty and their boxes collapsed. - **`organizationchart/toggle`:** in the PrimeVue reference, the toggle's centre is covered by its parent node (`elementFromPoint` returns `.p-organizationchart-node`), so a pointer click never reaches it. Noise was 0 in three local runs and in the canonical `docker-e4-r3/` capture, whose differences equal `docker-e4-r2/`.
