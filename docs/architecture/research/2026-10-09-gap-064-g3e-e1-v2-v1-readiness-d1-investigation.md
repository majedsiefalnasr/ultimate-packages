## 3. Established facts and evidence chain

1. **The test ID is not the reference route ID.** `cases-g3e.ts:223–233` maps `imagecompare/default` to Prime `imagecompare/sized`. `probe.ts` forms `http://localhost:6022/#/g3e/imagecompare/sized`; `main.ts` dispatches that route to `G3ECases`. The sized template projects images with `/media/landscape-1.png` and `/media/landscape-2.png` into ImageCompare.
2. **The reference asset configuration requires the app-local fixture path.** `ng/angular.json` declares `{ "glob": "**/*", "input": "fixtures", "output": "/" }` for the reference app. The repository supplies `tooling/prime-reference/ng/fixtures` as a tracked symlink (Git mode `120000`) whose target is `../fixtures`. Its normal resolution exposes the shared `fixtures/media/` images through the configured app-local input.
3. **The failed execution archives omit that path completely.** Both `production-input.tar` and `starting-worktree.tar` contain neither the `tooling/prime-reference/ng/fixtures` symlink nor descendants at that app-local path. They do contain the shared image files at `tooling/prime-reference/fixtures/media/`. The latter alone does not supply the asset input path named in the unchanged Angular configuration.
4. **The earlier successful experiment archive preserves the link.** `X/src.tar` contains a symlink member at `tooling/prime-reference/ng/fixtures` pointing to `../fixtures`, alongside the same shared image bytes. The compared Angular config, reference template/bootstrap, case table, loader and readiness sources are byte-identical between the two input sets and the currently inspected files. This is a concrete input difference, not evidence that every other environment characteristic was equal.
5. **The retained manifests omit the same tracked symlink.** Neither starting nor post-implementation file-hash manifest has an entry for `tooling/prime-reference/ng/fixtures`; both have the shared PNG entries. Current filesystem inspection reports `is_file() == false`, `is_dir() == true` for the directory symlink. Thus those manifests do not establish complete preservation of this asset-path topology, even where all listed regular-file hashes agree. Historical integrity records remain untouched; this finding qualifies their coverage for this specific link only.
6. **The original failure is image readiness on PrimeNG.** The saved runner observes Prime before Ultimate. Its readiness loop polls each matching image for `complete && naturalWidth > 0`. The first case failed at that assertion after 5000 ms, before returning the Prime observation or calling Ultimate. This is the assertion timeout, not expiry of the separate 120000 ms test timeout. The report contains no completed comparison rows; `root-style` did not run.
7. **No fixture-byte change is shown.** The two shared PNGs have identical local/failed-archive/successful-experiment hashes and valid PNG signatures. Their IHDR headers declare 800×600. Header inspection and byte identity do not prove successful browser decoding, serving or rendered dimensions.
