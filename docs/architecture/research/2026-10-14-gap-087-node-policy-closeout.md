## Result

GAP-087's Node engine mismatch is resolved on merged source and in the actual Release install. The private root declares `engines.node: "^24.15.0"` with `private: true`, `packageManager: "pnpm@9.6.0"`, and `.npmrc` `engine-strict=true`. Select mode, Version, and Publish each pin Node `24.15.0` before their unchanged frozen installs; CI already pinned that version. README Development guidance states the same private-workspace policy. The reviewed implementation changed only `package.json`, `.github/workflows/release.yml`, and `README.md`; it changed no dependency, lockfile, test, CI workflow, release control flow, or published-package consumer contract.

The Release workflow is **still failing** for a separate reason reached after the repaired install: `changesets/action/select-mode@v2.1.2` rejects the existing Changesets CLI v2. It selected no mode. Version and Publish were skipped, so their installs are statically aligned but dynamically unverified. This closeout does not claim a successful release or authorize a Changesets repair.
