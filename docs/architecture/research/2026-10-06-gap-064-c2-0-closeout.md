## Outcome

C2-0 is the separately authorized corrective step that ADR-052 X-2 requires before G3-C2. It covers only Angular `UContextMenu`.

- **R1 — positioning after render (timing only).** `show()` schedules the unchanged `position()` with `afterNextRender` (component injector) instead of a `queueMicrotask` that ran before the `@if (render())` list existed. Before the fix the menu stayed at the CSS default (0, 0); it now opens at `pageX + 1, pageY + 1`, with the existing viewport flip and 0 clamp, and `ZIndex` is applied. There is no cancellation state: the latest right-click wins, and hiding or destroying before the callback never re-shows the menu. This matches PrimeNG 21.1.9's timing (`onBeforeEnter`).
- **R2 — non-global host trigger (Option (b)).** The class doc comment no longer claims a `target` input. It documents the host-element right-click trigger as an Ultimate adaptation, and the need to give the host a hit area or use `global`. The Default story gives the host an inline-styled hit area (`display: block; min-height: 6rem; border: 1px dashed #999;`).
- **R3 — verification.** 7 new unit tests and a new `packages/ng/e2e/context-menu.spec.ts` with 4 layout tests × 3 engines. No screenshots, no accessibility scan.
- **R4 — provenance.** Three `docs/architecture/provenance/ng.json` entries for the changed source files, plus a `MIGRATION.md` §8 entry.
- **Unchanged.** No Vue, React, TieredMenu, CSS, public API, template or DOM change. No scroll-aware placement. No repository-wide provenance remediation.
