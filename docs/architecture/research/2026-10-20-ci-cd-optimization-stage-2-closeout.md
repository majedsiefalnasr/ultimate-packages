Replaying the 43 merged PRs through the new classifier with the real closures, against the ADR-069 classifier on `986fe941`:

- `[]`: #11, #17, #22, #25, #26, #27, #29, #30, #31, #40, as the Spec expects.
- `["react","vue"]`: #16 and #28, as the Spec expects.
- **Two differences the Spec did not list:** #7 and #39 give `[]` and `["react"]` instead of all three. Their only non-framework change is `.github/workflows/ci.yml`, which is on `NON_BROWSER_PATHS`. This is correct: the classifier gates only Browser-workflow jobs, and GitHub loads `browser.yml`, which never reads `ci.yml`. Both PRs predate the ADR-068 split, when `ci.yml` itself held the Playwright jobs; those ran in the CI workflow regardless of any classification.
- Every other PR gives the same frameworks as before. Scope is unchanged for all 43.
