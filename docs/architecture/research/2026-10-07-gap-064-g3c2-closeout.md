That run measured nothing new: it read a stale, git-ignored coverage summary from 2026-09-09. It is invalid evidence and is withdrawn. The current coverage scope counts all story files at 0%, and the 92.13% baseline predates the stories. This scope and baseline issue is recorded as GAP-091 (`BLUEPRINT_GAPS.md`).
- **Component and source coverage did not regress.** The style modules, key files and `.vue` components have identical covered and total line counts at both commits.
- **Scope of this correction.** It does not change the G3-C2 implementation outcome and does not reopen the tranche. No implementation, test, coverage configuration or baseline was changed.
