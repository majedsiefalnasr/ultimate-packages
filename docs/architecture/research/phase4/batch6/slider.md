## Shared foundation evidence and limits

- Angular `packages/ng-core/src/basecomponent/base-component.ts:15-36,56-76`: declares `dt`/`unstyled`, registers component and token styles unconditionally, no PT. Component inheritance must be read with the mapped product file.
- React `packages/react-core/src/base/component-base.ts:12-35`: component hook accepts component name/style module. The product registers `slider` (`packages/react/src/slider/slider.tsx:55`), matching Aura's `slider` key (`packages/themes/src/presets/aura/index.ts:65,170`), but `packages/react/src/slider/slider-style.ts:3-18` explicitly uses no `dt()` calls and hard-codes colors and geometry. This is an ADR-067 architecture nonconformance despite the correct key; computed styles were not checked in a running app. Vue `packages/vue-core/src/base/base-component.ts:26-42` registers styles; `packages/vue/src/slider/BaseSlider.ts:15-49` derives and registers its own style. These foundations alone do not prove an individual component uses a feature; mapped files show actual use.
- NG PT/unstyled upstream inheritance is from Prime BaseComponent; Vue PT is visible at `ptm`/`ptmi`, React at `ptm` in the mapped Prime source. This analysis does not prove SSR, keyboard, real form integration, touch, screen-reader, localization or stylesheet rendering behavior.
- Inventory caveats: `docs/inventory/angular-choice-range/README.md:58-62`, `docs/inventory/react-choice-range/README.md:70-74`, `docs/inventory/vue-choice-range/README.md:36-37`, `docs/inventory/angular-text-entry/README.md:54-55`, `docs/inventory/react-text-entry/README.md:31`, `docs/inventory/vue-text-entry/README.md:31-33`, `docs/inventory/angular-numeric-date-color-file/README.md:65`, `docs/inventory/react-numeric-date-color-file/README.md:73`.
