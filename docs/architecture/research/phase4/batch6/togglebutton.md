## Interpretation and decisions

- Row 16 React is **C, reference defect** by user ruling: pinned PrimeReact runtime and product both expose a checked native checkbox, despite published text describing a button/aria-pressed. Naming and keyboard behavior remain separate rows. Rows 17–20 document the independently observable naming and keyboard behavior. `PRD:14-45`; `PR:47-52,112-132`; `UR:77-106`.
- Row 33 Angular is C after the 2026-11-21 host probe, which checked that native host `class` coexists with the component's generated class, including after dynamic changes; no browser claim is made. Rows 33–35 now separate class placement, additional generic root attributes, and style on a separate native input. React and Vue verdicts have their own source evidence. Phase 4 decisions line 64.
- PrimeNG `inputId` and `autofocus` are inert declarations, and PrimeReact `children` is unused. Those rows compare shipped capabilities. PrimeVue’s declarations also describe native form naming, but its `name` serves the form registry and is not bound to a native submission control. PrimeReact's `name` is present in the event `target` and can pass to its wrapper via `getOtherProps`, but the input does not bind it. Ultimate also binds `name` to its checkbox, which is an additional native submission affordance. Angular's inherited Prime `name` and `required` inputs do not bind corresponding native attributes onto the non-native host. Angular Forms validators and `ngModel` naming operate through the consumer's form directives. `PN:43-72,152-171`; `PNE:6-30`; `PVT:107-114`; `PV:2-17`; `PVE:109-125`; `PR:27-45,100-132,141-153`; `PRB:24-44`; `PRC:440-441`; `UR:68-72,86-106`.
- The default-only Vue row scores initialization. Both bases share the guarded write path in pinned source. Non-boolean Vue values can render differently, but the public ToggleButton model is boolean. PrimeVue uses raw values for label/icon selection and `aria-pressed`, and strict boolean for the checked data/class. Ultimate uses strict boolean in those bindings. This is outside the supported boolean-value comparison. `PVT:101-110`; `PV:8-16,19-23,61-76`; `UV:8-19,49-65`; `PVE:46-60,89-98,127-129`; `UVE:25-37,61-65,79-85`.
- Open Phase 5 architectural decisions include how Vue should provide forms integration and how Angular should close the inherited but unwired unstyled/scoped token surfaces. Earlier minimal-port comments and superseded ADRs are history. D-PT already supplies the Phase 4 classification. `ADR:169-171`; `UVB:28-54`; `UVE:13-24,79-85`; `UNT:21-36,50-76`; external Phase 4 decisions lines 13–18, 24–31.
