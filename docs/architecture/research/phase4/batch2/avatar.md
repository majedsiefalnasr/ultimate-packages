## 4. Decisions needed

1. Content priority and image error: A match each Prime contract; B retain common image-first behavior and document mixed-prop and failure effects. Decide whether a changed image resets failed state.
2. Custom content, Vue icon slot, React fallback URL and click styling: A provide Prime-equivalent customization; B retain the smaller API and its gaps.
3. Group offsets: A use logical tokenized size-specific offsets; B retain fixed left offset with RTL/size limitations.
4. D-PT: choose implementation scope for the ruled-missing Avatar and AvatarGroup pass-through in Phase 5; deferral retains the gaps.

## 5. Reference defects

`docs/prime-reference/components/avatar.md:53,100` describes fallback to label/icon without qualification. PR:61-74 only performs it for `imageFallback='default'` when no `onImageError` callback is supplied. PN:96-98 and PV:21-24 only emit errors; Ultimate source comments saying these Prime implementations fall back are inaccurate commentary.
