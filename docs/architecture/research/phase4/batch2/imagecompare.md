- PrimeNG documents a tabindex default of 0 but does not initialize it (PN:42–47); PrimeVue declares 0 but does not bind it (PVB:9, PV:2; `docs/prime-reference/components/imagecompare.md:57`).
- Prime docs describe labels for the slider while source labels the root (PN:23–29, PV:2–5). The documentation example has mismatched label IDs (`docs/prime-reference/components/imagecompare.md:68`).
- Label descriptions are swapped (`docs/prime-reference/components/imagecompare.md:58`). Structural CSS references an undeclared `imagecompare.handle.border.style` token (`docs/prime-reference/components/imagecompare.md:78`).
