## Decisions needed

- D-PT: implement per-part pass-through or retain the gap; implementation adds granular attribute control and API maintenance. Classification is fixed as missing by the ruling.
- Angular footer wrapper: conditionally omit an empty wrapper to avoid a potential extra body gap, or retain the current DOM. Blockable target: add target integration or retain the current scoped blocker; `packages/ng/src/block-ui/block-ui.ts:27` excludes target mode. Header/footer projection supplies region content, so template and facet spelling is not counted as a separate functional gap.
- React render functions and header-image rule: add compatibility or require callers to supply nodes and image styling. Styling architecture is addressed by D-SHARED #1.
- Decide shared root attributes and styling controls under D-SHARED #2 and #5.
