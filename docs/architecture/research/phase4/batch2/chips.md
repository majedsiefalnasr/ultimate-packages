## 4. Phase 5 scope items (not classification disputes)

None of these items changes a verdict. Items 1–2 are product-direction questions; items 3–5 are Phase 5 implementation scope.

1. **Angular chips** — Prime removed it; options: (a) nothing (AutoComplete multiple covers it; family belongs to AutoComplete); (b) keep as-is. Consequence: no NG row to maintain; Ultimate has no NG input-chips, so cross-framework API parity depends on AutoComplete work.
2. **Vue Prime component is deprecated** (`InputChips.vue:78` warning) — decide whether Ultimate keeps a standalone input-chips for all frameworks or converges on AutoComplete multiple.
3. **React hard-coded styling** — D-SHARED #1 (architecture).
4. **Behavioral deviations kept vs Prime** (trim on add, `>=` max, Vue scalar `removedItem`) — decide copy Prime (array payload, raw whitespace) or document as improvements; affects migrants' handlers.
5. **Missing React features** (veto, keyfilter, removable, templates, tooltip, variant, ARIA ids) — to decide in Phase 5; not intentional (no in-force ADR).
