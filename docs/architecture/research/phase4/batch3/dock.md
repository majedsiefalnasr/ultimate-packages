## Decisions and reference defects

Decide React magnification and neighbor behavior (recommend parity), item templates/slots, Space activation and wrapping vs clamping, React Aura token integration under ADR-067, and breakpoint/tooltip/header-footer scope. Reference defects: REC says all frameworks handle NumpadEnter; PrimeNG source handles Enter/Space only (`NGA/dock/dock.ts:294-343`). PrimeReact sets item role then overwrites it with `none` (`PRA/dock/Dock.js:238,244`); its click handler always preventDefault (`:47-53`) conflicting with URL navigation. PrimeNG router condition repeats `itemTemplate` (`NGA/dock/dock.ts:102-104`). PrimeVue DockSub reads processed item via `processedItem.item` while wrapper passes raw model (`PVA/dock/DockSub.vue:112-114`, `PVA/dock/Dock.vue:3`); command impact unconfirmed. Reference says Vue forwards focus/blur, source wrapper does not.
