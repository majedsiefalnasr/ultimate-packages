## 4. Decisions needed

No row is "intentional": the exclusions in NG inplace.ts:30-40 and the "smaller surface than upstream" comments are source comments, not accepted ADRs.

1. Built-in close button (row 10, NG + React). Options: (a) implement closable/closeIcon/aria; (b) accept an ADR that closing is only via closeCallback. Consequence of (a): parity with PrimeReact, adds Button dependency; (b) matches PrimeNG/PrimeVue direction (NG marks closable deprecated). Recommendation: (b) for NG (Prime deprecated it), (a) for React only if React consumers need it.
2. React Space key (row 9). Options: add Space (Prime parity, a11y doc lists it) or keep Enter-only. Recommendation: add Space; low cost, matches role=button expectations.
3. React/NG `active` sync (row 2). Options: make `active` input/prop win after first interaction (Prime behavior) or keep current local override. Recommendation: Prime behavior; current behavior is a recorded known-defect.
4. Imperative API/ref (row 13) and React rest props/forwardRef (row 14): confirm whether these are in scope. Recommendation: include ref/rest for React.
5. pt (row 15): per D-PT, Phase 5 decides implementation.
6. Architecture (row 17 React): migrate to dt()/Aura tokens per ADR-067 (Inplace is not an ADR-067 exception).
