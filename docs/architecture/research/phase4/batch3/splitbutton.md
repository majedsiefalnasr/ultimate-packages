## Architecture and reference findings

React is covered by ADR-067 for Aura consumption; `packages/react/src/split-button/split-button-style.ts:3-6` uses literal 6px and no token refs. Theme-variable registration alone does not establish consumption. Decide nested TieredMenu behavior, dropdown accessibility, customization/overlay configuration, and React Aura use; recommendations in agent analysis favored parity and Aura, but implementation/priority belongs to Phase 5. PrimeVue declares `buttoncontent` but template does not render it; PrimeReact declares `transitionOptions` but does not forward it; PrimeNG declares `plain` but template does not use it. These are reference defects; do not count them as required capabilities without resolving the source behavior. Existing inventory action records describe historical environment/build failures, not current product tests. Remaining checks: popup placement/dismissal/focus, accessible state/name, Angular host/root merge, React computed theme/dark mode, nested components.
