## 4. Decisions needed

1. Templates, slots, icons, lifecycle events and motion: A implement framework-specific Prime surfaces, gaining parity at maintenance cost; B preserve the smaller API, accepting missing customization and events.
2. State and lifetime: A match each Prime contract; B standardize behavior while documenting state loss and Angular parent-update consequences.
3. D-PT requires pass-through be classified missing; choose implementation scope in Phase 5. Deferral leaves the gap.
4. Angular region labeling: resolved by user ruling 2026-11-18 — row 10 complete + reference-defect against pinned source; same dangling reference exists in both sources when non-toggleable. This is source parity only, not an accessibility-quality conclusion. React content-reference access remains a separate gap. Cross-cutting decisions are in D-SHARED.

## 5. Reference defects
