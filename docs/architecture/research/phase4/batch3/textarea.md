Decide Angular autoResize match to Prime's resize triggers/no-max-height behavior; size, filled state/global variant fallback where Prime offers them; React KeyFilter/Tooltip and Vue Forms formField; Angular automatic ng-invalid styling and Vue CSS completeness. Phase 5 decides implementation; scope comments alone do not establish intentional difference. PrimeNG and PrimeVue style keys have trailing space `'p-textarea-resizable '` (P-NS:22; P-VS:9), cosmetic. PrimeNG autoResize relies on comparing with NaN without max-height (P-N:139); pinned source is oracle. Ultimate comments U-N:35-41,119-124 claim exact port but `|| "0"` differs. No docs/source conflict affects a classification.

(config.inputStyle || config.inputVariant)`, a global fallback (`packages/core/src/config/PrimeVue.js:10-11`).
