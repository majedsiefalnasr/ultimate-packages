## Decisions and reference defects

PrimeNG documentation claims aria-current and hidden separators; source lacks both (`NGA/breadcrumb/breadcrumb.ts:83-85,160-162`) and the conflict is recorded in REC. The user ruled the two Angular capabilities N/A against pinned source. Decide whether separators should be hidden from assistive technology, whether to add templates/slots and separator customization, how React icon values should render, and React Aura-token integration under ADR-067. Other source discrepancies: REC describes PrimeNG styleClass deprecated, but source declaration has no deprecation tag (`NGA/breadcrumb/breadcrumb.ts:191`). PrimeReact regular model items render labels only (`PRA/breadcrumb/BreadCrumb.js:163-176`); list PT declaration uses HTMLUListElement despite ordered-list markup. PrimeVue defines `disabled()` without guarding click (`PVA/breadcrumb/BreadcrumbItem.vue:28-41`).

Resolved 2026-11-21 by source trace: React and Vue default home icon (n/a, neither Prime offers one) and Vue item class (missing). Still open: verify React icons and Vue router-link against exact Prime APIs. Source-only.
