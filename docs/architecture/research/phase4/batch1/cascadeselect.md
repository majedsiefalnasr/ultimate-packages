## 4. Phase 5 scope items (not classification disputes)

None of these items changes a verdict; each cell is scored against its own framework's oracle. Item 2 is already mandated by ADR-067. Recommendations are Phase 5 input only.

1. **Scope of the port.** Ultimate file headers state keyboard drill, search, virtual scroll, templates, pt and NgModule are "deliberately excluded" (comments only, e.g. `CascadeSelect.vue:62-65`, `cascade-select.ts:64-69`). No accepted ADR backs it, so those stay missing. Options: (a) full parity in Phase 5, (b) staged: keyboard/ARIA first, templates/messages later, (c) record an ADR excluding some. Recommendation: (b).
2. **React theming (row 21).** ADR-067 requires Aura `dt()` + preset key `cascadeselect`. Moving to tokens changes colours/size visibly. Needs go-ahead.
3. **Event contract (row 4).** React `onChange(value)` vs Prime event object; Vue never emits `change`. Options: match Prime `onChange({originalEvent,value})`, or keep value-only and record deviation.
4. **Accessibility model (row 16).** Prime uses hidden input + `aria-activedescendant`; React Prime uses a different listbox model. Decide target model for all three (recommend PrimeNG/PrimeVue model).
5. **`optionGroupChildren` string vs array (row 3).** Needed for multi-level data.
6. **pt (row 23)** — D-PT, Phase 5.
7. **React Portal and `appendTo` (row 11)** — overlay clipping risk inside `overflow:hidden` parents.
