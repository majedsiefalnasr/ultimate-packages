## 4. Phase 5 scope items (not classification disputes)

None of these items changes a verdict. Prioritization and implementation belong to Phase 5.

1. **Region rendering (row 3).** Prime React/Vue always render all three region divs; Ultimate renders them conditionally. Options: (a) always render (parity; empty divs exist, may affect `gap` and spacing); (b) keep conditional (cleaner DOM; deviates from Prime). Recorded as a default-differs flag; React/Vue stay partial under source parity. Phase 5 choice.
2. **Vue attribute fall-through (row 6)** — decided once in D-SHARED #2.
3. **React start/center/end function form (row 2)** — add or accept ReactNode only.
4. **Left/right aliases and `getBlockableElement` (rows 5, 7)** — Prime keeps them (deprecated). Options: add for parity, or record an ADR to skip deprecated surface.
5. **pt (row 11)** — Phase 5 implementation; D-PT.
