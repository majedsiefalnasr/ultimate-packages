## 4. Decisions needed

1. Three-value control in Angular/Vue: (A) follow each pinned oracle and keep n/a; (B) add an Ultimate-owned three-value control, with independently defined behavior. B increases cross-framework API scope; the Prime replacement only visually indicates indeterminate. Recommendation: A for this reference analysis, while leaving a product decision open.
2. Locale: (A) supply configurable/localized announcement labels, matching Prime; (B) formally accept fixed English. A supports localization; B reduces API surface. ADR-056's prior no-new-i18n statement does not establish this concrete missing capability as an intentional exclusion.
3. Unstyled, variant and shared configuration: (A) implement matching surfaces; (B) record an explicit narrower contract. A provides consumer customization; B needs a new ruling. Pass-through is already ruled missing by the user and requires no re-decision.

## 5. Reference defects

- Prime renders null as `aria-checked=false` (P:122-135), losing a programmatic distinction from false, although three values exist. Ultimate emits `mixed` (U:99). This is a source observation, not a requirement to reproduce it. User ruling (2026-11-19): row 8 is complete with this Prime reference defect recorded.
- Prime styled documentation lists `p-tristatechkbox`/`p-chkbox*`, while PB:5-14 emits `p-tristatecheckbox`/`p-checkbox*` (`docs/prime-reference/components/tristatecheckbox.md:79-82`).
