## 4. Phase 5 scope items (not classification disputes)

None of these items changes a verdict. Rows 13–15 are scored against PrimeReact's checkbox contract; choosing another accessibility pattern is a Phase 5 design decision.

1. **Mount auto-advance (row 3).** Omitted by an implementation comment only.
   - A: Match Prime: emit `onChange` on mount when `empty=false` and value is null. Consequence: parity; a controlled consumer gets an `onChange` without user action.
   - B: Record an ADR keeping the current behavior. Consequence: row becomes intentional; consumers must give a non-null initial value.
2. **Role (rows 13–15).** Prime is a checkbox with a binary checked state plus a live region; Ultimate is a button whose name changes.
   - A: Follow Prime (checkbox role + live region + locale label). Consequence: parity; Prime itself only exposes checked/unchecked, not which option.
   - B: Keep `role="button"` and add a live region. Consequence: an Ultimate-owned accessibility pattern; needs an ADR and real screen-reader testing either way.
3. **Angular / Vue availability.** A: keep n/a per oracle. B: add an Ultimate-owned component in both, in line with the one-umbrella goal. Consequence of B: new scope with no Prime oracle to compare against.
4. **Common surfaces (rows 16–21, 23).** A: implement (autoFocus, ref, invalid, variant, tooltip, style/attributes, unstyled). B: record a narrower contract by ADR. pt is already ruled missing (D-PT); no new decision.

## 5. Reference defects

1. Prime's Space handler toggles without checking `readOnly` (P:87-92 calls `toggle` directly; only `onClick` checks, P:29-33). A focused read-only Prime MultiStateCheckbox can still be changed by keyboard. Ultimate guards both (U:96); do not copy Prime.
2. R:46 says each option may supply `className`; the source never applies an option's className (PB:13-16 uses `props.className`; only `style` comes from the option, PB:19-21).
3. R:82 already notes the styled-mode doc lists `p-multistatechkbox`/`p-chkbox*`, not the emitted `p-multistatecheckbox`/`p-checkbox*` (PB:9-12). Confirmed.
4. Ultimate story comment says the root shows "none" for empty; that is Ultimate behavior, not Prime (Prime reads locale `nullLabel`, default "Not Selected"). Context only.
