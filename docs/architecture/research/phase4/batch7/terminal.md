## Reference defects

- Prime docs claim ARIA labeling for the input, but source spreads unknown attrs on host/root; reaching input requires PT (`docs/prime-reference/components/terminal.md:105-107`).
- PrimeReact uniquely supports ArrowUp history and `clear`; PrimeNG/PrimeVue don't (`docs/prime-reference/components/terminal.md:109,147-150`). This is a framework source difference, not doc conflict.
- PrimeVue TerminalService type documentation is copy-pasted/wrong (`docs/prime-reference/components/terminal.md:89`).
