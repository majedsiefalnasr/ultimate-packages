## Default flags

- All three default to single-panel mode; product defaults match Prime (`multiple=false`). PrimeReact empty state defaults to `activeIndex:null`, while Ultimate React uses `undefined`; both mean no active tab: record as an API/default flag, not a class change.
- PrimeNG and PrimeVue `selectOnFocus=false`; product Vue also defaults false. Ultimate NG/React do not expose this setting and do not activate on focus; the differing API availability is reflected in the selection behavior rows, not a default flag.
