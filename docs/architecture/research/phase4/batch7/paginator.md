## 4. Default flags

- PrimeReact emits `aria-current="true"` on page links (`PRA/paginator/PageLinks.js:54`); PrimeNG and PrimeVue emit `page`. Ultimate emits `page`.
- Prime NG `first` button is not disabled on the first page (`PNG/paginator/paginator.ts:54`), while its `last` button is disabled on the last page (`:109`); Ultimate disables both. Corrected 2026-11-21: the earlier note said neither was disabled.
- Prime defaults: report template `{currentPage} of {totalPages}` (NG) versus `({currentPage} of {totalPages})` (React, `PaginatorBase.js:82`).

## 5. Reference defects

- Removed 2026-11-21: the earlier note that PrimeNG's `changePage` payload lags one change was wrong. `first` is a getter over `_first` (`PNG/paginator/paginator.ts:270-275`) and `_first` is assigned at `:501` before the state is built at `:502-506`, so the payload carries the new offset, like Ultimate. No class changes.
