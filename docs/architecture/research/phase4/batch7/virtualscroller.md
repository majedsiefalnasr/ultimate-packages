## Default flags

- Prime orientation defaults vertical (`PN scroller.ts:405`, PR `VirtualScrollerBase.js:73`, PV `BaseVirtualScroller.vue:25-28`); product is vertical-only, so default matches while horizontal/both remain missing.
- Product `numToleratedItems` defaults to half the viewport (NG `scroller.ts:187-193`, React `scroller.tsx:91-94`, Vue `Scroller.vue:83-87`), matching Prime's half-viewport default (PN `scroller.ts:310-317`, PR `VirtualScroller.js:183-195`, PV `VirtualScroller.vue:290-298`).

## Reference defects

Prime VirtualScroller references `virtualscroller.loader.mask.background`, `.mask.color`, and `.loader.icon.size` without an Aura token module, in both Prime style sources and Ultimate's shared style. Record as Prime reference defect; the parity classes remain C because both implementations use the same shared style/token paths.
