## 6. Foundation, style imports, dt, registered key

- Angular: Prime imports `style as autocomplete_style` from `@primeuix/styles/autocomplete` (`PNGs:1-6`). Product is a hand-ported local CSS (`NGs:1-12`, CSS uses `dt('autocomplete.*')` at `NGs:27-80`); extends `UBaseInput` (`NG:118`), overlay via `UOverlay` (`NG:15,89-91`); registered key `"autocomplete"` (`NG:119-121`; registration `NGb:56-76`). dt/unstyled inputs declared (`NGb:34-36`), not read.
- React: Prime uses own `@layer primereact` CSS with no design tokens (`PRB:44-146`). Product CSS hand-authored with no `dt()` (`RAs:1-12`); registered via `useComponentBase({componentName:"autocomplete", styleModule})` (`RA:81-84`). ADR-067 (`docs/architecture/DECISIONS.md:787-803`): AutoComplete is not among the listed exceptions; the missing `dt()` use is recorded as evidence, not as a blanket verdict.
- Vue: Prime `AutoCompleteStyle` via `PVB:3`. Product CSS uses `dt('autocomplete.*')` (`VAs:28-78`); key `"autocomplete"` registered by `registerComponentStyle` at `VAb:38-40`; `createBaseInput` at `VAb:16`.
