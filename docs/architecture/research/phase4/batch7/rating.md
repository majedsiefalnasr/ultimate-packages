## Foundations and decisions

Angular references rating tokens in `packages/ng/src/rating/rating-style.ts:12–47` and inherits style registration via `NG:87–89`. Vue registers its rating style module in `packages/vue/src/rating/BaseRating.ts:25–34`, and its styles reference gap and icon tokens in `packages/vue/src/rating/rating-style.ts:10–45`. React invokes the component hook at `R:50` but the registered module uses hard-coded colors and spacing without `dt()` (`packages/react/src/rating/rating-style.ts:8–17`). The product Aura preset includes Rating (`packages/themes/src/presets/aura/index.ts:60,165`). ADR-067 applies (`docs/architecture/DECISIONS.md:787–803`). This is an architectural conformance finding. PrimeReact's legacy CSS is the behavioral comparison target for React styling, and the artifact does not claim computed style parity.

User rulings resolve React rows 9, 11 and 13 individually: pinned PrimeReact source governs; each unsupported documented capability is N/A with a reference-defect note, while product radio semantics, English labels and standard Space activation are recorded as extras. This does not establish accessibility quality. Space activation remains separate from clearing a selected rating.
