## Default flags

- React `closeOnEscape` defaults false (`packages/react/src/tooltip/tooltip.tsx:45`), matching PrimeReact (`tooltip/TooltipBase.js:106`); position defaults to right and show/hide delays to 0 in both (`TooltipBase.js:110-123`, product `tooltip.tsx:40-43`). PrimeReact default show/hide events are mouseenter/mouseleave (`TooltipBase.js:111,123`), matching product's default hover behavior.
- Ultimate Vue defaults Escape on, delays to zero, and autoHide on (`packages/vue/src/tooltip/tooltip.ts:39-44`).

## Reference defects

- Tooltip docs promise `aria-describedby`, but the pinned directive/component sources do not write it (`docs/prime-reference/components/tooltip.md:101`; PN `tooltip/tooltip.ts`, PR `Tooltip.js`, PV `Tooltip.js`).
