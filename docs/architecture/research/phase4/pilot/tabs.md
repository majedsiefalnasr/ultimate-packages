## Keyboard / Home-End reference defect

- All three Prime accessibility docs list Home="last", End="first" (`docs/prime-reference/components/tabs.md:128`); all pinned sources do Home→first, End→last (PNG `tabs/tab.ts:152-164`; PR `tabview/TabView.js:179-191`; PV `primevue/src/tab/Tab.vue:76-86`). All products follow source (`packages/ng/src/tabs/tab.ts:84-90`; `packages/react/src/tabs/tab-view.tsx:184-191`; `packages/vue/src/tabs/Tab.vue:77-82`).
- User ruling (2026-11-19): Vue keyboard row C, following pinned source; docs reversal recorded as reference defect.
- Only Angular and React keyboard rows are P, solely because PageUp/PageDown strip scrolling is absent (React also lacks NumpadEnter). The Home/End defect does not affect their class.

## Shared foundation / preset note (outside counts)

- Angular and Vue use family-local style modules (`packages/ng/src/tabs/tabs-style.ts:1-53`, `packages/vue/src/tabs/tabs-style.ts:1-54`), not a central `@ultimate/uix-styles/tabs` entry; both call `dt`; Aura Tabs tokens exist (`packages/themes/src/presets/aura/tabs.ts:1-96`).
- Angular base registers theme variables (`packages/ng-core/src/basecomponent/base-component.ts:56-77`); Vue `createBaseComponent` only registers module CSS (`packages/vue-core/src/base/base-component.ts:39-41`).
- React uses handwritten CSS, no Aura `dt` (`packages/react/src/tabs/tabs-style.ts:1-65`); route to shared-styling track under D-SHARED #1 (ADR-067).
