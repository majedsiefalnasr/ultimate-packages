## Defaults and shared foundation notes

- PrimeVue modal is null (false-like), Ultimate defaults true. User approved a default flag, not a class change. The row is P for the mask behavior, not the default.
- PrimeReact closeOnEscape defaults true, not false; the earlier recovery note was corrected.
- Angular/Vue consume `@ultimate/uix-styles/dialog` (`packages/uix-styles/src/dialog/index.ts:1-44`); React uses handwritten CSS without `dt()` (`packages/react/src/dialog/dialog-style.ts:1-23`) although Aura Dialog tokens exist (`packages/themes/src/presets/aura/dialog.ts:26-49`). Runtime preset resolution was not checked.
- Mask class mismatch: Angular/Vue emit `u-overlay-mask` without a matching product rule; base styles define `.p-overlay-mask` (`packages/uix-styles/src/base/index.ts:57-71`). This supports row 1 but was not browser-verified.
- Event rows 12 include callbacks tied to separately missing drag/resize/maximize features; they are still separate API capabilities and remain counted. No tests or browser checks were run.
