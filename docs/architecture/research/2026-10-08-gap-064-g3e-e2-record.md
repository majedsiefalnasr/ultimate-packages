- **D3 (B-2 base roles):**

  - carousel: `.u-carousel-item-list { transition: transform 500ms ease 0s; }` — Prime sets the transition inline at runtime; Ultimate's existing value is retained as its mechanism. (E2-5 option (b) would add a second D4 role.)

  - carousel: `.u-carousel-item { flex-shrink: 0; box-sizing: border-box; }` — Prime sizes items with an inline `flex` basis; Ultimate needs non-shrinking items for its translate. `.u-carousel-prev-button:disabled, .u-carousel-next-button:disabled { opacity: 0.5; cursor: default; pointer-events: none; }` — retained with the native buttons (PX-E1, G3-D R-D1 precedent).
