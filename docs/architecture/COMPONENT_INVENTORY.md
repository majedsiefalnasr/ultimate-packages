# Component Inventory

Full classification of all top-level source areas under PrimeNG 21.1.9's `packages/primeng/src/` (117 directories, confirmed authoritative via `tar -tzf .vendor-cache/primeng-21.1.9.tar.gz | grep -E "packages/primeng/src/[^/]+/$"` — see `docs/architecture/checksums.json` for the pinned tarball and `docs/architecture/PROVENANCE.md` for the PrimeNG package-level provenance record).

This is the Phase 2 deliverable referenced by the approved spec (`docs/superpowers/specs/2026-08-29-phase-2-ultimateng-foundation-design.md`, Component Inventory section) and by `docs/architecture/PROVENANCE.md`'s PrimeNG entry. It supersedes that spec section's representative-row sample with the full ~117-row table.

Schema (11 columns): **Component** | **Prime source path** | **Category** | **Dependencies** | **UIX dependencies** | **Angular-specific responsibilities** | **Style dependencies** | **Accessibility responsibilities** | **Migration classification** | **Migration phase** | **Risk**.

- **Migration classification:** `ADAPT` (incorporate, PrimeNG source is the right design reference) / `NOT NEEDED` (no Ultimate equivalent planned — pure build/lint/internal tooling, or superseded by an Ultimate-owned mechanism) / `NEEDS ARCHITECTURE DECISION` (adaptation approach is unresolved, deferred pending a design decision).
- **Migration phase:** `Phase 2` (built and incorporated this phase) / `Later Phase` (planned, not yet started) / `Not Applicable` (paired with `NOT NEEDED`).
- **Risk** is a qualitative flag for later-phase planning (Low/Medium/High), not a Phase 2 blocker.

**Note on directory counting (corrected during review — the original arithmetic here double-counted `config`):** the 12 rows above map to 15 of PrimeNG's top-level source directories: `basecomponent`, `baseeditableholder`, `config`, `focustrap`, `overlay`, `bind`, `ripple`, `autofocus`, `fluid`, `badge`, `button`, `checkbox`, `dialog`, `menu`, `tooltip` — 15 directories grouped into 12 rows (`basecomponent`+`baseeditableholder`+`config` form the "BaseComponent tier" row; `focustrap`+`overlay` form the "FocusTrap + Overlay" row). Of these 15, **14 are exclusively built this phase** and **1 (`config`) is split-scope** — Task 4's `UltimateConfig` covers only a minimal `unstyled`/`ripple` subset (ADR-018), while `config`'s full surface is separately tracked below as `NEEDS ARCHITECTURE DECISION`, not fully closed by this phase's row. `icons` (the 16th directory touched this phase) is likewise split-scope: 4 of ~89 leaf icon components are built, the rest deferred, tracked in the cross-cutting section below rather than as a "built" directory here.

Reconciling against the authoritative 117-directory count: **14 exclusively built** + **2 split-scope** (`config`, `icons`, each counted once in the "remaining" total below since neither is fully closed) + **101 exclusively remaining** = 117. The "Remaining" section below therefore covers **103 areas** (101 exclusively-remaining directories, plus `config` and `icons` each appearing there once to record their unfinished scope) — not the "105" figure an earlier draft of this document stated, which resulted from counting `config` as both fully built (above) and fully remaining (below) simultaneously.

**Post-Phase-2 addition (Angular Form Foundation workstream):** outside of, and after, Phase 2 proper, two further directories moved from exclusively-remaining to exclusively-built via this document's Form components table below — `basemodelholder` (`UModelHolder`, GAP-018 resolved for this slice) and `inputtext` (`UInputText`, the first real consumer). This raised the reconciled count to **16 exclusively built** (the original 14, plus `basemodelholder` and `inputtext`) + **2 split-scope** (`config`, `icons`, unchanged) + **99 exclusively remaining** = 117, with the "Remaining" section covering 101 areas.

**Further post-Phase-2 addition (same Angular Form Foundation workstream, GAP-038 closure):** two more directories have since moved from exclusively-remaining to exclusively-built — `baseinput` (`UBaseInput`, GAP-038 resolved) and `inputnumber` (`UInputNumber`, the first real `UBaseInput` consumer, shipped via a real secondary entry point — see the InputNumber row and GAP-009's refinement note in `BLUEPRINT_GAPS.md`). This raises the reconciled count to **18 exclusively built** (16 + `baseinput` + `inputnumber`) + **2 split-scope** (`config`, `icons`, unchanged) + **97 exclusively remaining** = 117. The "Remaining" section below therefore now covers **99 areas** (97 exclusively-remaining directories, plus `config` and `icons` each appearing there once to record their unfinished scope) — down from 101, reflecting `baseinput` and `inputnumber` moving to built.

**Phase C Batch 1 addition (`feature/phase-c-batch-1-migration`, Task Group Z):** 74 further directories have moved from exclusively-remaining to exclusively-built, closing every Angular-eligible canonical capability in the approved Phase C Batch 1 specification (`docs/superpowers/specs/2026-09-17-phase-c-batch-1-migration-design.md` §3) and implementation plan (`docs/superpowers/plans/2026-09-17-phase-c-batch-1-migration-implementation.md`), per that plan's own Task Group Z (§8) instruction to move each closed Angular capability's row from Remaining to Built: RadioButton, ToggleSwitch, ToggleButton, Textarea, InputMask, InputOTP, Password, Autocomplete, Select, MultiSelect, CascadeSelect, Listbox, SelectButton, Rating, Slider, Knob, ColorPicker, DatePicker, FileUpload, KeyFilter, FloatLabel, IconField, InputIcon, InputGroup, InputGroupAddon, IftaLabel (Form, 26 rows = 24 canonical capabilities, since IconField/InputIcon and InputGroup/InputGroupAddon are each one canonical capability spanning two Prime directories/rows); ConfirmDialog, ConfirmPopup, ContextMenu, Drawer, DynamicDialog, Popover, OverlayBadge, StyleClass (Overlay, 8 rows/8 capabilities); Breadcrumb, MegaMenu, Menubar, PanelMenu, Steps, Stepper, Tabs, TieredMenu, Dock, SpeedDial, SplitButton (Navigation, 11 rows/11 capabilities); Accordion, Avatar, AvatarGroup, BlockUI, ButtonGroup, Card, Carousel, Chip, Divider, Fieldset, Galleria, Image, ImageCompare, Inplace, Message, MeterGroup, Panel, ProgressBar, ProgressSpinner, ScrollPanel, ScrollTop, Skeleton, Splitter, Tag, Terminal, Timeline, Toast, Toolbar, AnimateOnScroll (Panel/Layout/Display/Feedback, 29 rows/29 capabilities).
