# Menu API

A flat navigation/command list rendered as an ARIA menu, either inline or as a popup overlay, with roving-tabindex keyboard navigation.

- Package: @ultimate/ng
- Source: packages/ng/src/menu/menu.ts
- Category: Navigation

## Props

- **model** (type UMenuItem&#91;&#93;, optional, default &#91;&#93;): An array of menuitems.
- **popup** (type boolean, optional, default false): Defines if menu would displayed as a popup. When set, the menu stays hidden until opened imperatively via toggle(event)/show(event)/hide(event?).
- **appendTo** (type HTMLElement &#124; (() =&#62; HTMLElement) &#124; undefined, optional): Target element to attach the popup overlay to; defaults to document.body.
- **baseZIndex** (type number, optional, default 0): Base z-index value to use in layering of the popup.
- **closeOnEscape** (type boolean, optional, default true): Whether Escape closes the popup; has no effect in inline mode.

## Events

- **onShow** (output, semantic id shown): void — callback to invoke when the popup is shown; emitted synchronously at the end of show() (popup mode only, no motion).
- **onHide** (output, semantic id hidden): void — callback to invoke when the popup is hidden; emitted synchronously at the end of hide() (popup mode only, no motion).
