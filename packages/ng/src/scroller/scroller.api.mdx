# Scroller API

A virtual-scroll windowing primitive that renders only the items currently within (plus a tolerated buffer around) the visible viewport, used internally by Table and other large-list components rather than directly by end users.

- Package: @ultimate/ng
- Source: packages/ng/src/scroller/scroller.ts
- Category: Data

## Props

- **items** (type unknown&#91;&#93;, optional, default &#91;&#93;): The full, un-windowed array of items to be virtually scrolled.
- **itemSize** (type number, optional, default 0): Height in pixels of a single rendered item, used for windowing math and content-height calculation.
- **numToleratedItems** (type number &#124; undefined, optional, default undefined): Number of extra items rendered as a buffer beyond the visible viewport on each side; when undefined, resolves to half the computed number of items in the viewport.
- **loading** (type boolean &#124; undefined, optional, default undefined): When true, shows the built-in loader overlay and sets aria-busy on the root element.
- **disabled** (type boolean, optional, default false): When true, bypasses windowing entirely and renders every item in &#96;items&#96; (no virtualization).
- **lazy** (type boolean, optional, default false): When true, enables lazy-load notification: onLazyLoad fires whenever the windowed first index changes on scroll.

## Events

- **onLazyLoad** (output, semantic id lazyLoad): &#123; first: number; last: number &#125; — emitted (via Promise.resolve().then()) after the internal \_first field is updated locally, only when lazy() is true and the windowed first index changes on scroll.
