# Paginator API

A page-navigation control (first/prev/next/last plus numbered page links) driven by first/rows/totalRecords, used standalone or composed inside Table/DataView for paging.

- Package: @ultimate/ng
- Source: packages/ng/src/paginator/paginator.ts
- Category: Data

## Props

- **first** (type number, optional, default 0): Zero-relative index of the first record to be displayed.
- **rows** (type number, optional, default 0): Number of rows to display per page.
- **totalRecords** (type number, optional, default 0): Number of total records.
- **pageLinkSize** (type number, optional, default 5): Number of page links to display.

## Events

- **onPageChange** (output, semantic id pageChanged): PaginatorPageChangeEvent (&#123; page, first, rows, pageCount &#125;) — emitted after the internal \_first signal is updated locally, on any in-bounds first/prev/next/last/page-link click.
