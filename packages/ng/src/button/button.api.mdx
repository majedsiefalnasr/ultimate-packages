# Button API

A clickable button control with optional icon, loading state, and severity/size/style modifiers.

- Package: @ultimate/ng
- Source: packages/ng/src/button/button.ts
- Category: Primitive

## Props

- **label** (type string &#124; undefined, optional): Text of the button.
- **icon** (type string &#124; undefined, optional): Name of the icon.
- **iconPos** (type "left" &#124; "right" &#124; "top" &#124; "bottom", optional, default left): Position of the icon.
- **loading** (type boolean, optional, default false): Whether the button is in loading state.
- **disabled** (type boolean, optional, default false): When present, it specifies that the component should be disabled.
- **severity** (type string &#124; undefined, optional): Defines the style of the button.
- **raised** (type boolean, optional, default false): Add a shadow to indicate elevation.
- **rounded** (type boolean, optional, default false): Add a circular border radius to the button.
- **text** (type boolean, optional, default false): Add a textual class to the button without a background initially.
- **outlined** (type boolean, optional, default false): Add a border class without a background initially.
- **size** (type "small" &#124; "large" &#124; undefined, optional): Defines the size of the button.
- **fluid** (type boolean, optional, default false): Spans 100% width of the container when enabled.
