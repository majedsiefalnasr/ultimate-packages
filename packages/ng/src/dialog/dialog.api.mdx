# Dialog API

A modal (or non-modal) overlay window that renders projected content above the page, with focus trapping and Escape-key dismissal.

- Package: @ultimate/ng
- Source: packages/ng/src/dialog/dialog.ts
- Category: Overlay

## Props

- **visible** (type boolean, optional, default false): Specifies the visibility of the dialog.
- **header** (type string &#124; undefined, optional): Title text of the dialog.
- **closable** (type boolean, optional, default true): Adds a close icon to the header to hide the dialog.
- **closeOnEscape** (type boolean, optional, default true): Specifies if pressing escape key should hide the dialog.
- **modal** (type boolean, optional, default true): Defines if background should be blocked when dialog is displayed.
- **role** (type "dialog" &#124; "alertdialog", optional, default "dialog"): ARIA role override for the dialog's root element. Defaults to "dialog"; UConfirmDialog overrides this to "alertdialog" to match real upstream's own p-confirmdialog composition (GAP-049).

## Events

- **visibleChange** (output, semantic id visibleChange): boolean — notifies changes in the visibility state of the component (the controlled-visibility companion to the &#96;visible&#96; input, emitted on close).
- **onShow** (output, semantic id shown): void — emitted once the enter motion's promise resolves after &#96;visible&#96; transitions to true.
- **onHide** (output, semantic id hidden): void — emitted synchronously when &#96;visible&#96; transitions to false, before the leave motion completes.
