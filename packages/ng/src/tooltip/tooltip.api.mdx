# Tooltip API

Shows advisory content next to a host/target element on hover or focus. An attribute directive in Angular and Vue; a target-based component in React.

- Package: @ultimate/ng
- Source: packages/ng/src/tooltip/tooltip.ts
- Category: Overlay

## Props

- **uTooltip** (type string &#124; undefined, optional): Content of the tooltip.
- **uTooltipPosition** (type "top" &#124; "bottom" &#124; "left" &#124; "right", optional, default "top"): Position of the tooltip.
- **uTooltipDisabled** (type boolean, optional, default false): When present, it specifies that the tooltip should be disabled.
