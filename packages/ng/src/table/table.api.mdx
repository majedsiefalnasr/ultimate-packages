# Table API

Table renders tabular data with sorting, filtering, selection, pagination, virtualization, and row/cell editing.

- Package: @ultimate/ng
- Source: packages/ng/src/table/table.ts
- Category: Data

## Events

- **sortFieldChange** (output, semantic id sort-changed): string &#124; undefined — the clicked column's field, emitted by onSort() on every header click in single-sort mode; sortOrderChange (always 1) and multiSortMetaChange (multi-sort mode) are sibling outputs emitted from the same handler, not folded into this one.
- **selectionChange** (output, semantic id selection-changed): T &#124; T&#91;&#93; — the next selection value, emitted by onRowClick() on a row click when selectionMode is set. Single mode always emits the clicked row; multiple mode emits the toggled selection array.
- **firstChange** (output, semantic id page-changed): number — the composed UPaginator's onPageChange.first, re-broadcast by onPaginatorPageChange() after the internal \_first signal is updated locally. A sibling rowsChange output re-broadcasts .rows from the same handler.
- **onLazyLoad** (output, semantic id lazy-load): &#123; first: number; last: number &#125; — the composed UScroller's own onLazyLoad payload, re-emitted unchanged by onScrollerLazyLoad().
- **editingRowKeysChange** (output, semantic id editing-rows-changed): Record&#60;string, boolean&#62; — the next editing key-map, emitted by initRowEdit() when a row enters edit mode and by the save/cancel exit path when it leaves it.
- **expandedRowKeysChange** (output, semantic id expanded-rows-changed): Record&#60;string, boolean&#62; — the next expansion key-map with the toggled row's dataKey identity flipped, emitted by toggleRowExpansion().
- **onRowExpand** (output, semantic id row-expand): &#123; originalEvent: Event; data: T &#125; — emitted by toggleRowExpansion(), after expandedRowKeysChange, when the row becomes expanded.
- **onRowCollapse** (output, semantic id row-collapse): &#123; originalEvent: Event; data: T &#125; — emitted by toggleRowExpansion(), after expandedRowKeysChange, when the row becomes collapsed.
