# Scroller API

A virtual-scroll windowing primitive that renders only the items currently within (plus a tolerated buffer around) the visible viewport, used internally by Table and other large-list components rather than directly by end users.

- Package: @ultimate/vue
- Source: packages/vue/src/scroller/base-scroller.ts
- Category: Data

## Props

- **items** (type Array, optional, default &#91;&#93;): The full, un-windowed array of items to be virtually scrolled.
- **itemSize** (type Number, optional, default 0): Height in pixels of a single rendered item, used for windowing math and content-height calculation.
- **numToleratedItems** (type Number, optional, default null): Number of extra items rendered as a buffer beyond the visible viewport on each side; when null, resolves to half the computed number of items in the viewport.
- **disabled** (type Boolean, optional, default false): When true, bypasses windowing entirely and renders every item in &#96;items&#96; (no virtualization). Declared directly on Scroller.vue, not in the shared base-scroller.ts triad.
- **loading** (type Boolean, optional, default false): When true, shows the built-in loader overlay and sets aria-busy on the root element. Declared directly on Scroller.vue, not in the shared base-scroller.ts triad.
- **lazy** (type Boolean, optional, default false): When true, enables lazy-load notification: 'lazy-load' emits whenever the windowed first index changes on scroll. Declared directly on Scroller.vue, not in the shared base-scroller.ts triad.

## Events

- **lazy-load** (emit, semantic id lazyLoad): &#123; first: number; last: number &#125; — emitted (via Promise.resolve().then()) after the internal &#96;first&#96; data property is updated locally, only when &#96;lazy&#96; is true and the windowed first index changes on scroll. NOT named 'onLazyLoad' — the declared emits-array name is 'lazy-load'.
