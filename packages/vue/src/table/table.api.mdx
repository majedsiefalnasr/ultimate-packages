# Table API

Table renders tabular data with sorting, filtering, selection, pagination, virtualization, and row/cell editing.

- Package: @ultimate/vue
- Source: packages/vue/src/table/base-table.ts
- Category: Data

## Props

- **value** (type Array, optional, default &#91;&#93;): The full, unpaginated array of records to render.
- **dataKey** (type String, optional, default ""): Field name used to resolve a row's identity for selection equality and row editing.
- **columns** (type Array, optional, default &#91;&#93;): Column definitions: field to resolve per row, and header text to render.
- **sortMode** (type String, optional, default "single"): Whether a single field or multiple fields (via multiSortMeta) drive sorting.
- **sortField** (type String, optional, default undefined): Field currently sorted on, in single-sort mode.
- **sortOrder** (type Number, optional, default 0): Sort direction for sortField, in single-sort mode.
- **multiSortMeta** (type Array, optional, default &#91;&#93;): Priority-ordered field/order pairs driving sorting, in multi-sort mode.
- **filters** (type Object, optional, default &#123;&#125;): Per-field filter criteria; a &#123;operator, constraints&#125; group AND/ORs its constraints, matching React's shape.
- **selectionMode** (type String, optional, default undefined): When set, enables row-click selection (single replaces selection, multiple toggles rows in/out of it).
- **selection** (type &#91;Object, Array&#93;, optional, default undefined): Currently selected row (single mode) or rows (multiple mode).
- **compareSelectionBy** (type String, optional, default "equals"): Row-identity comparator for selection matching: dataKey-based field identity, or full structural deepEquals.
- **paginator** (type Boolean, optional, default false): When true, renders a composed UPaginator beneath the table and slices the filtered/sorted rows to the current page.
- **first** (type Number, optional, default 0): Zero-relative index of the first record on the current page.
- **rows** (type Number, optional, default 0): Number of rows to display per page.
- **totalRecords** (type Number, optional, default 0): Total record count, forwarded to the composed UPaginator.
- **rowsPerPageOptions** (type Array, optional, default &#91;&#93;): Row-count choices offered by the composed UPaginator.
- **virtualScrollerOptions** (type Object, optional, default undefined): When set, renders rows through a composed UScroller (via its named 'content' scoped slot) instead of a plain tbody map.
- **lazy** (type Boolean, optional, default false): When true, enables the composed UScroller's lazy-load notification, forwarded via lazy-load.
- **editMode** (type String, optional, default undefined): Enables the row-edit-init affordance ('row') or cell-level editing ('cell').
- **editingRows** (type Array, optional, default &#91;&#93;): Array of rows currently in edit mode (Vue's array-append idiom, distinct from ng's/react's dataKey-based key-map shape).
- **rowGroupMode** (type String, optional, default undefined): Row-grouping display strategy when groupRowsBy is set.
- **groupRowsBy** (type String, optional, default undefined): Field used to group adjacent rows sharing the same value.

## Events

- **sort** (emit, semantic id sort-changed): &#123; sortField, sortOrder &#125; in single-sort mode or &#123; multiSortMeta &#125; in multi-sort mode — emitted by sortColumn() on every header click. NOT named 'onSort' — the declared emits-array name is 'sort'. Vue props are one-way, so this never assigns back to sortField/sortOrder/multiSortMeta itself.
- **selection-change** (emit, semantic id selection-changed): T &#124; T&#91;&#93; — the next selection value, emitted by selectRow() alongside a companion 'update:selection' v-model emit carrying the identical payload (mirroring Paginator's own 'page' + 'update:first'/'update:rows' dual-emit pattern). Single mode always emits the clicked row; multiple mode emits the toggled selection array.
- **page** (emit, semantic id page-changed): PaginatorPageChangeEvent — the composed UPaginator's own 'page' event, re-emitted verbatim by onPaginatorPage() as Table's own 'page' event. NOT named 'onPageChange' or 'firstChange'.
