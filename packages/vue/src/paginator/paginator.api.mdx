# Paginator API

A page-navigation control (first/prev/next/last plus numbered page links) driven by first/rows/totalRecords, used standalone or composed inside Table/DataView for paging.

- Package: @ultimate/vue
- Source: packages/vue/src/paginator/base-paginator.ts
- Category: Data

## Props

- **first** (type Number, optional, default 0): Zero-relative index of the first record to be displayed.
- **rows** (type Number, optional, default 0): Number of rows to display per page.
- **totalRecords** (type Number, optional, default 0): Number of total records.
- **pageLinkSize** (type Number, optional, default 5): Number of page links to display.

## Events

- **page** (emit, semantic id pageChanged): &#123; page, first, rows, pageCount &#125; — emitted after the internal d_first data property is updated locally, on any in-bounds first/prev/next/last/page-link click. NOT named 'onPageChange' — the declared emits-array name is 'page'.
- **update:first** (emit, semantic id firstChanged): number — v-model companion emit for the &#96;first&#96; prop, enabling v-model:first two-way binding. Emitted alongside 'page' in the same changePage() call.
- **update:rows** (emit, semantic id rowsChanged): number — v-model companion emit for the &#96;rows&#96; prop, enabling v-model:rows two-way binding. Emitted alongside 'page' in the same changePage() call.
