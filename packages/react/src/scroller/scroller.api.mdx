# Scroller API

A virtual-scroll windowing primitive that renders only the items currently within (plus a tolerated buffer around) the visible viewport, used internally by Table and other large-list components rather than directly by end users.

- Package: @ultimate/react
- Source: packages/react/src/scroller/scroller.tsx
- Category: Data

## Props

- **items** (type unknown&#91;&#93;, required): The full, un-windowed array of items to be virtually scrolled.
- **itemSize** (type number, required): Height in pixels of a single rendered item, used for windowing math and content-height calculation.
- **numToleratedItems** (type number, optional): Number of extra items rendered as a buffer beyond the visible viewport on each side; when omitted, resolves to half the computed number of items in the viewport.
- **disabled** (type boolean, optional, default false): When true, bypasses windowing entirely and renders every item in &#96;items&#96; (no virtualization).
- **lazy** (type boolean, optional, default false): When true, enables lazy-load notification: onLazyLoad fires whenever the windowed first index changes on scroll.
- **loading** (type boolean, optional): When true, shows the built-in loader overlay and sets aria-busy on the root element.

## Events

- **onLazyLoad** (callback-prop, semantic id lazyLoad): (event: &#123; first: number; last: number &#125;) =&#62; void — optional prop, called (via Promise.resolve().then()) only when both &#96;lazy&#96; and &#96;onLazyLoad&#96; are truthy and the windowed first index changes on scroll. Component owns its own &#96;firstState&#96; internally regardless of whether this callback is supplied.
