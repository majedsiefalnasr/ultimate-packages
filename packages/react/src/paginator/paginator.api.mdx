# Paginator API

A page-navigation control (first/prev/next/last plus numbered page links) driven by first/rows/totalRecords, used standalone or composed inside Table/DataView for paging.

- Package: @ultimate/react
- Source: packages/react/src/paginator/paginator.tsx
- Category: Data

## Props

- **first** (type number, required): Zero-relative index of the first record to be displayed.
- **rows** (type number, required): Number of rows to display per page.
- **totalRecords** (type number, required): Number of total records.
- **pageLinkSize** (type number, optional, default 5): Number of page links to display.

## Events

- **onPageChange** (callback-prop, semantic id pageChanged): (event: PaginatorPageChangeEvent) =&#62; void — required prop. Fully controlled: the component holds no page state of its own, so a parent that ignores this callback sees no UI advance.
