# Table API

Table renders tabular data with sorting, filtering, selection, pagination, virtualization, and row/cell editing.

- Package: @ultimate/react
- Source: packages/react/src/table/table.tsx
- Category: Data

## Props

- **value** (type T&#91;&#93;, required): The full, unpaginated array of records to render.
- **dataKey** (type string, optional): Field name used to resolve a row's identity for selection equality and row editing.
- **columns** (type UTableColumn&#91;&#93;, required): Column definitions: field to resolve per row, and header text to render.
- **sortMode** (type SortMode, optional, default "single"): Whether a single field or multiple fields (via multiSortMeta) drive sorting.
- **sortField** (type string, optional): Field currently sorted on, in single-sort mode.
- **sortOrder** (type 1 &#124; 0 &#124; -1, optional, default 0): Sort direction for sortField, in single-sort mode.
- **multiSortMeta** (type SortMeta&#91;&#93;, optional, default &#91;&#93;): Priority-ordered field/order pairs driving sorting, in multi-sort mode.

- **paginator** (type boolean, optional, default false): When true, renders a composed UPaginator beneath the table and slices the filtered/sorted rows to the current page.

## Events

- **onSort** (callback-prop, semantic id sort-changed): (event: UTableSortEvent) =&#62; void — optional prop. UTableSortEvent is &#123; sortField, sortOrder &#125; in single-sort mode or &#123; multiSortMeta &#125; in multi-sort mode, called by handleSort() only when supplied. Table holds no sort state of its own — a header click is inert without this callback, matching Paginator's no-uncontrolled-fallback convention.
- **onSelectionChange** (callback-prop, semantic id selection-changed): (selection: T &#124; T&#91;&#93;) =&#62; void — optional prop, called by handleRowClick() only when both selectionMode and onSelectionChange are supplied. Single mode always calls with the clicked row; multiple mode calls with the toggled selection array.
- **onPage** (callback-prop, semantic id page-changed): (event: PaginatorPageChangeEvent) =&#62; void — optional prop, wired as a bare forward directly to the composed UPaginator's own onPageChange callback (onPageChange=&#123;(event) =&#62; onPage?.(event)&#125;) — not a renamed re-emission of a locally-owned value, unlike ng's firstChange.
